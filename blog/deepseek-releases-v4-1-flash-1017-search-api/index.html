DeepSeek Launches V4.1-Flash-1017 Checkpoint and Public Search API

According to DeepSeek's self-reported evaluation, the updated Mixture-of-Experts checkpoint cuts task completion time, posts higher agent benchmark marks, and unlocks DeepSeek's internal web search index.

In short

  • DeepSeek-V4.1-Flash-1017 introduces an updated checkpoint under the MIT license with a 1 million token context window and 384,000 maximum output tokens.
  • The model scored 77.0 on DeepSWE v1.1 and 42.3 on Terminal-Bench 4.0, while DeepSeek claims in its technical documentation that it reduces token generation length and task execution runtime.
  • DeepSeek opened its in-house web Search and Fetch APIs to all developers at $0.75 per 1,000 successful requests, with free access via select harnesses through October 31, 2026.
  • The checkpoint runs on a 40-layer causal encoder-decoder architecture with 552 billion backbone parameters, activating 8 billion parameters during prefill and 16 billion during decode.

On October 17, 2026, artificial intelligence laboratory DeepSeek deployed an updated model checkpoint, DeepSeek-V4.1-Flash-1017, across its web interface, mobile application, and developer API. Alongside the model release, the company opened public access to its proprietary web Search and Fetch APIs, giving external developers programmatic access to the search infrastructure powering its consumer applications.

The update serves as a direct revision to the earlier DeepSeek-V4.1-Flash architecture rolled out in September 2026. According to the company's model card on Hugging Face, the 1017 checkpoint targets improvements across reasoning, coding, autonomous agent execution, and multimodal visual tasks. DeepSeek describes the release as a Pareto improvement in performance and operating expense, delivering higher benchmark accuracy while decreasing output length and runtimes.

Architecture and Memory Optimization

DeepSeek-V4.1-Flash-1017 maintains the architectural profile of the V4.1-Flash line, utilizing a multimodal Mixture-of-Experts (MoE) design with 40 Transformer layers divided evenly into a 20-layer causal encoder and a 20-layer decoder. Detailed architectural reporting from MarkTechPost states the model contains 552 billion backbone parameters alongside 196 billion Engram parameters. In operation, it activates 8 billion parameters per token during the prefill phase and 16 billion parameters per token during token decoding.

Memory management sits at the core of the checkpoint's efficiency gains. The release uses Causal Encoder-Decoder (CED) mechanics, projecting the decoder's global key-value (KV) states from final encoder hidden layers to reduce prefill compute overhead. Attention operations rely on Compressed Sparse Attention 2 (CSA2), with layers cycling through Full, Reindex, and Reuse modes to share key indices. By packing the main KV cache into FP4 representations, global KV requirements drop to 890 bytes per token, roughly one-fourth of the memory footprint of the earlier V4-Flash model, while sliding-window attention (SWA) bounded replay reduces persistent cache storage to roughly one-eighth.

The system supports a 1 million token context window and maximum generation limits reaching 256,000 to 384,000 output tokens. DeepSeek's technical recommendations advise sampling with a temperature of 1.0 and top_p of 1.0. For prompt processing, DeepSeek published deepseek-recipe, an open-source Rust library with Python bindings designed to parse multi-turn chat conversions, thinking tokens, tool calls, and image data into the exact token layouts required by the model.

Benchmark Performance Across Coding and Agent Harnesses

To train the checkpoint on autonomous end-to-end tasks, DeepSeek implemented reinforcement learning with self-feedback (RLSF). As reported by The Decoder, this method allows the system to evaluate its own intermediate logic and code generation during complex development cycles without relying on separate reward models or human labelers. The company showcased projects constructed from scratch using the technique, including 3D architectural models and browser games.

In evaluations published in the DeepSeek API documentation change log, V4.1-Flash-1017 posted gains across all 11 standardized benchmarks compared to the base September checkpoint:

  • DeepSWE v1.1 (Mini-SWE-V2 harness): 77.0, rising from 74.2 on the previous Flash release and outpacing Claude Opus 5 (74.0) and GPT-5.6 Sol (73.0).
  • Terminal-Bench 4.0 (Claude Code harness): 42.3, compared to 31.2 previously, placing it ahead of GPT-5.6 Sol (39.9) and GLM 5.3 (37.9), though trailing Claude Opus 5 (51.8).
  • Automation-Bench v1.0.6: 60.5, improving from 54.8.
  • Agents' Last Exam: 35.4, up from 31.8.
  • Apex Bench v1.1: 72.1, climbing from 64.6.
  • HLE (without tools): 42.6 overall and 44.0 on the text-only subset, behind Claude Opus 5 at 56.3.
  • Multimodal Benchmarks: BabyVision reached 92.5 (with tools), and Chartography reached 83.0.

Analysis reported by The Decoder highlighted that the model's more succinct generation behavior lowered test costs significantly. On the DeepSWE evaluation, the updated Flash checkpoint executed tasks at an average cost just under $0.20 per completed task at top performance, compared to around $0.50 for the September version. Rival models charted on the same evaluation landed between $2 and over $10 per task.

Search and Fetch API Availability

Simultaneously with the checkpoint rollout, DeepSeek introduced public developer endpoints for web search: POST /v1/tools/search and POST /v1/tools/fetch. As outlined in the DeepSeek API documentation updates, the services run on an in-house search engine that DeepSeek claims indexes hundreds of billions of web pages and serves hundreds of millions of queries daily.

The Search API accepts queries with filters such as site:, lang:, after:, and before:, returning between 1 and 50 results containing authority tiers (rated 0 to 4) and reranking scores (rated 0 to 3). The Fetch API extracts individual target URLs and returns the contents formatted as clean Markdown. DeepSeek notes that its search engine applies filtering mechanisms designed to suppress SEO spam, geographic ranking manipulation, and low-quality synthetic text.

Pricing for both the Search and Fetch endpoints is set at $0.75 per 1,000 successful queries, with empty and failed requests incurring no charge. Each account receives a baseline rate limit of 5 queries per second. DeepSeek announced in its developer news bulletin that server-side calls routed through the DeepSeek Harness, Claude Code, and Codex developer environments remain free of charge until October 31, 2026, at 16:00 UTC.

Developer Deployment and Model Availability

For existing API users, accessing DeepSeek-V4.1-Flash-1017 requires no parameter restructuring. The company updated the production alias deepseek-flash to route directly to the new checkpoint. As noted by AI Weekly, developers consuming the standard model name automatically transitioned to the updated behavior without an opt-out flag or migration process.

The model weights are published under an open MIT License on Hugging Face and ModelScope. DeepSeek recommends pairing the model with DeepSeek Harness version v0.2.1-rc.1 or later, while adding dedicated optimizations for developer tooling including Tencent CodeBuddy and WorkBuddy.

DeepSeek's cloud API structure applies peak rates of $0.30 per 1 million cache-miss input tokens and $1.20 per 1 million output tokens, with off-peak rates discounted by 50 percent. Cache hits are priced at $0.003 per million tokens. The model also exposes a reasoning effort scalar ranging from 1 to 100, mapped to standard low (50), high (75), and max (100) operational presets.

Questions people ask

How can developers access DeepSeek-V4.1-Flash-1017?

Developers can invoke the model via the DeepSeek API by specifying the model identifier deepseek-flash using standard OpenAI or Anthropic endpoint schemas. The weights are also available for self-hosting on Hugging Face and ModelScope under the MIT license.

What are the costs for the newly released Search and Fetch APIs?

Both the Search and Fetch endpoints are priced at $0.75 per 1,000 successful requests, with rate limits set to 5 queries per second per account. Calls made through DeepSeek Harness, Claude Code, and Codex are free until October 31, 2026, at 16:00 UTC.

How does DeepSeek-V4.1-Flash-1017 compare to larger commercial frontier models?

According to benchmarks released by DeepSeek, the model achieved a 77.0 score on DeepSWE v1.1 and 60.5 on Automation-Bench v1.0.6, surpassing models like Claude Opus 5 and GPT-5.6 Sol on those specific software tests. However, Claude Opus 5 retains higher scores on raw reasoning tasks such as HLE and Terminal-Bench 4.0.
