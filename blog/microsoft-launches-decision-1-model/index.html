Microsoft Launches Decision-1 AI Model for Fast Structured Decisions

Built on Alibaba's Qwen3.5-9B, the text-only model scores predefined options at $0.042 per million input tokens with zero output fees.

In short

  • Microsoft launched Microsoft-Decision-1, a 9-billion-parameter model designed exclusively for structured choices like routing, classification, and verification.
  • The model is post-trained on Alibaba's open-weight Qwen3.5-9B, with Microsoft planning to rebase future iterations on Microsoft AI and OpenAI foundations.
  • Microsoft reports 83.5% accuracy across 36 blind benchmarks, clocking in 35 times faster than GPT-6 Sol and 2.5 times faster than H2O-Lightning-4B.
  • Available in preview on Microsoft Foundry and OpenRouter, the API costs $0.042 per million input tokens with free output tokens.

On October 9, 2026, Microsoft introduced Microsoft-Decision-1, a 9-billion-parameter model tailored specifically for rapid, structured decision-making rather than conversational text generation. Built by post-training Alibaba's open-weight Qwen3.5-9B, the model targets high-volume operational tasks such as routing, data classification, and agent guardrails. By returning calibrated probability distributions over predefined options instead of generating open-ended prose, Microsoft Decision-1 aims to reduce inference latency and computational expenses in multi-step software pipelines.

Traditional large language models are engineered to reason in paragraphs or synthesize documents, but intermediate steps in automated workflows often require simple categorical determinations. Microsoft says that running every routing choice or intent check through a general-purpose generative model introduces unneeded latency and token overhead. The release places Microsoft directly into an emerging segment of purpose-built decision models, competing alongside releases from startups like Jev, open-source efforts from Cloudflare, and Amazon's Strands Decider 2B.

How Microsoft Decision-1 Operates in Workflows

Unlike standard chatbots, Microsoft-Decision-1 is strictly text-only and does not translate, converse, summarize, or draft responses, according to the Microsoft Foundry model catalog. When queried, an application sends a context payload along with a closed set of choices, such as support categories or workflow directives. The model evaluates the input in a single pass and returns a calibrated confidence score for each option, allowing developers to set programmatic thresholds for automated actions or human escalation.

Microsoft outlines several core deployment scenarios for the system, including:

  • Model and Tool Routing: Selecting the appropriate agent, API endpoint, or downstream model based on an incoming query.
  • Content Classification: Sorting inputs into predefined categories such as customer intents, technical bug types, or billing questions.
  • Evaluation and Verification: Judging whether an AI-generated draft meets specific rubric criteria or is grounded in provided evidence.
  • Agent Guardrails: Validating proposed tool calls or workflow actions before an autonomous agent executes them.

Microsoft's documentation emphasizes explicit guardrails for the model itself: it is not intended or evaluated to act as the sole automated decision-maker in consequential determinations regarding people, such as employment, healthcare, housing, credit, or legal rights.

Benchmark Performance and Internal Microsoft Testing

According to an announcement on Microsoft's Command Line blog, Microsoft-Decision-1 achieved the highest accuracy in an internal evaluation spanning 36 benchmarks and nearly 150,000 blind questions. Reports reviewing the company's test results put the model's average accuracy across those evaluations at 83.5 percent, registering an average latency of roughly 85 milliseconds.

On inference speed, Microsoft claims the model ran 2.5 times faster than its runner-up, H2O-Lightning-4B v1.1, and 35 times faster than OpenAI's GPT-6 Sol. Some secondary reporting from shattered.io also cited comparisons against Quyet-1.0-Large, though official Microsoft documentation focused on H2O-Lightning-4B and GPT-6 Sol. In adversarial stability evaluations, Microsoft reported the model was perturbation-stable 98.7 percent of the time, changing answers in only 1.3 percent of tested input variations. However, as noted by daily.dev, independent stress testing using adversarial suites like JevOut has not yet been conducted.

Microsoft Chief Executive Officer Satya Nadella stated that the company is already running the model internally across incident response, quality control, and scientific discovery. Within Microsoft's gaming division, Xbox Research applied Decision-1 to categorize more than 10,000 open-ended player feedback submissions into researcher-defined categories. The team reported classification quality competitive with GPT-5 while operating 80 to 100 times faster. Other internal groups have tested the model to grade Copilot response quality and guide adaptive replanning inside Microsoft Discovery.

Qwen Foundation and Future Rebasing Plans

The choice of Alibaba's Qwen3.5-9B as the underlying architecture highlights Microsoft's pragmatism in shipping small, specialized models quickly. Rather than waiting to adapt its proprietary frontier models or OpenAI's foundation models, Microsoft opted to fine-tune an established 9B open-weight base.

Microsoft has made clear that this foundation is transitional. In its launch materials, the company stated that future iterations will be rebased onto models developed by Microsoft AI (MAI) as well as OpenAI. While the base weights from Alibaba are open source, weights for Decision-1 itself are not being distributed, based on reporting from Data Studios cited by shattered.io. Developers must access the model via hosted cloud infrastructure.

Pricing and Availability

Microsoft-Decision-1 is currently available in public preview within the Microsoft Foundry Models Catalog, the Foundry Playground, and on OpenRouter according to Dealroom.co reporting, with OpenRouter listing the model under the identifier microsoft/microsoft-decision-1.

Pricing in Microsoft Foundry's US and EU data zones is set at $0.042 per million input tokens. Because the model outputs discrete probability scores and classification labels rather than generated text sequences, output tokens are free of charge. This pricing matches the rate set by competing decision startup Jev, positioning the model as an economical option for high-volume control loops where generative token billing would otherwise compound.

Questions people ask

What is Microsoft Decision-1 used for?

Microsoft Decision-1 is designed for high-speed, structured choices such as request routing, intent classification, AI response evaluation, and agent workflow control.

Can Microsoft Decision-1 generate paragraphs or write code?

No. Decision-1 is a text-only decision model that evaluates supplied inputs against a fixed set of predefined options, outputting calibrated probability scores rather than open-ended text.

What model architecture is Microsoft Decision-1 built on?

The model was post-trained on Alibaba's open-weight Qwen3.5-9B. Microsoft plans to rebase future iterations on Microsoft AI (MAI) and OpenAI models.

How much does Microsoft Decision-1 cost to run?

Usage costs $0.042 per million input tokens in Microsoft Foundry and OpenRouter, with no charge for output tokens.
