Nvidia Demands TSMC 3nm Process for Custom NVHBM Base Dies

To unify memory performance across suppliers, Nvidia is requiring Samsung, SK Hynix, and Micron to build custom NVHBM base dies on TSMC's 3nm node.

In short

  • Nvidia has directed Samsung, SK Hynix, and Micron to manufacture base dies for custom NVHBM using TSMC's 3nm process.
  • The core dies will rely on sixth-generation (1c) DRAM technology to match the standardized architecture.
  • Nvidia reports that the custom memory design delivers up to 30 percent higher memory bandwidth and 15 percent lower power consumption than standard HBM4E.
  • Samsung accepted the terms after an internal review, marking its first collaboration with TSMC at the HBM fabrication stage.
  • Samsung will retain in-house production for standard HBM and may offer its own foundry for NVHBM if TSMC capacity is exceeded.

Nvidia has instructed its primary memory suppliers—Samsung Electronics, SK Hynix, and Micron Technology—to manufacture the base dies for its upcoming custom high-bandwidth memory (NVHBM) on TSMC's 3-nanometer (3nm) node, according to reports from the Seoul Economic Daily published by CommonWealth Magazine and Wccftech. The directive establishes a unified production standard across multiple memory vendors and prompts Samsung to partner with TSMC at the HBM manufacturing stage for the first time.

Following an internal review, Samsung accepted Nvidia's terms despite operating its own commercial foundry. The arrangement breaks Samsung's traditional end-to-end approach for this custom memory tier, uniting the world's leading DRAM manufacturers under a single foundry process for NVHBM base dies.

Standardizing NVHBM Base Dies Across Memory Partners

Under the specifications set by Nvidia, the custom NVHBM integrates Nvidia's proprietary memory controller directly into the base die. To preserve architectural consistency, Nvidia requested that Samsung, SK Hynix, and Micron each fabricate these base dies exclusively through TSMC's 3nm process. For the memory core dies stacked on top, suppliers must deploy sixth-generation DRAM, also known as the 1c process.

Nvidia's primary objective behind mandating a shared foundry node is standardization. When different memory makers build base dies with disparate manufacturing nodes and internal libraries, the host chipmaker must run individual, lengthy verification procedures for each supplier's samples. By enforcing TSMC's 3nm technology across all three memory partners, Nvidia can verify a single base die design, eliminating redundant validation testing and accelerating time to volume deployment.

According to details reported by Wccftech, Nvidia claims its custom in-house memory architecture can yield up to 30 percent higher memory bandwidth than standard HBM4E while reducing power consumption by up to 15 percent. These custom memory stacks have been targeted for deployment in Nvidia's future Feynman GPU architecture.

Samsung Adapts Its Foundry Strategy

For Samsung, the move represents a tactical adjustment in its high-bandwidth memory roadmap. Historically, Samsung has relied on a turnkey model, fabricating both the DRAM core dies and the underlying logic base dies within its own semiconductor facilities. By agreeing to TSMC-manufactured base dies for NVHBM, Samsung is temporarily setting aside its foundry rivalry with TSMC to protect its share of Nvidia's component supply chain.

Samsung does not plan to abandon its in-house manufacturing capabilities entirely. The company will continue using its own foundries for standard HBM production and for custom memory products developed for other semiconductor clients, as noted by CommonWealth Magazine. Furthermore, Samsung is currently evaluating whether its proprietary foundry lines could be qualified to manufacture NVHBM base dies in the event that global demand outstrips TSMC's available 3nm capacity.

High-bandwidth memory production remains central to Samsung's broader semiconductor financial recovery. Boosted by surging demand for AI hardware components, Samsung's foundry division reduced its annual operating losses by 41 percent, cutting deficits from 6.74 trillion won (approximately $5.1 billion) in 2025 down to 3.92 trillion won (approximately $2.95 billion) in 2026, according to Wccftech. Complying with Nvidia's multi-vendor manufacturing blueprint ensures Samsung retains a critical role in next-generation accelerator hardware alongside SK Hynix and Micron.

Questions people ask

What is Nvidia NVHBM?

NVHBM is Nvidia's custom high-bandwidth memory solution that integrates a proprietary Nvidia memory controller directly into the base die. Nvidia claims the architecture delivers up to 30 percent higher bandwidth and 15 percent lower power consumption compared to standard HBM4E.

Why is Nvidia requiring memory suppliers to use TSMC's 3nm process?

Nvidia mandated TSMC's 3nm node so that Samsung, SK Hynix, and Micron use an identical manufacturing standard for base dies. This standardization allows Nvidia to avoid testing and qualifying different base die variants from each individual vendor.

Will Samsung stop manufacturing base dies in its own foundries?

No. Samsung will continue manufacturing base and core dies in-house for standard HBM and for other custom chip customers. It is also assessing whether its own foundries could produce NVHBM base dies if TSMC's capacity cannot meet demand.
