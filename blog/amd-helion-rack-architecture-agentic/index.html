AMD Unveils Helion Rack Architecture for Agentic AI Workloads

The open rack reference design scales up to 32,768 Zen 6 EPYC cores with optional Instinct GPUs to manage concurrent agent orchestration and enterprise inference.

In short

  • AMD introduced the Helion agentic AI rack reference design based on Open Compute Project specifications at the OCP Global Summit.
  • A CPU-only configuration packs up to 32,768 Zen 6 EPYC cores across 128 sockets for high-density agent sandboxing and execution.
  • An enterprise configuration blends EPYC CPUs with up to 16 AMD Instinct MI350P GPUs and an integrated token router.
  • Eight server partners—including Dell, HPE, Cisco, and Supermicro—plan to release Helion-based hardware starting in November 2026.

On October 12, 2026, AMD announced AMD Helion, an open rack-scale reference design engineered to handle the specific operational demands of agentic AI workloads. Unveiled at the Open Compute Project (OCP) Global Summit in San Jose, the blueprint provides server manufacturers with specifications for building high-density systems tailored to autonomous software agents rather than large-scale model training, according to AMD's official announcement.

Agentic AI systems require infrastructure that differs fundamentally from traditional training clusters. While foundation model pre-training depends heavily on tightly coupled GPU fabrics, running concurrent software agents involves building software, database querying, code execution, and complex workflows. AMD aims to address these heterogeneous compute demands by combining high-density 6th Gen AMD EPYC central processors, flexible GPU nodes, and an integrated token router inside an open-standard chassis.

Tailored Configurations: Hyperscale Density and Enterprise Hybrid Systems

According to AMD's Helion product architecture documentation, the platform is split into two primary architectures: a CPU-only hyperscale design and a hybrid enterprise configuration.

The CPU-only configuration targets hyperscalers, neoclouds, and sovereign operators that maintain separate accelerated clusters for raw model inference. Powered by 6th Gen AMD EPYC 9006 series processors (codenamed "Venice"), this design packs up to 128 sockets per rack, delivering up to 32,768 "Zen 6" x86 CPU cores. Operators can balance power consumption and density using distinct blade designs: dense servers offering 256 cores at 400W, balanced servers running 256 cores at 600W, or technical compute nodes using 96 high-frequency cores operating at up to 5.0 GHz.

For enterprise environments that need compute and acceleration within a single footprint, the enterprise configuration integrates CPU and GPU nodes into one system. This layout pairs EPYC compute blades with up to 16 AMD Instinct MI350P GPUs housed across two independent 5U server chassis, as detailed by Tom's Hardware. The rack also incorporates dedicated general-purpose blades using EPYC 9006 SP7, SP8, and 9006X SP7 processors to support background storage and databases.

Architectural Focus: Token Routing and Independent GPU Nodes

Unlike AMD's previously introduced Helios platform—which was built for frontier-scale training and massive inference with 72 MI455X GPUs linked via a scale-up fabric—Helion focuses strictly on execution efficiency. AMD confirmed that the two eight-GPU server nodes in Helion operate independently without an interconnecting scale-up fabric, reflecting enterprise agent needs rather than monolithic model training.

A key functional component of the enterprise design is an integrated token router. AMD states that this mechanism directs agents' model calls across frontier models in the cloud and open-source models running in the rack.

"Agentic AI is not a single workload. It spans personal agents, enterprise applications, code execution and complex workflows, each with different compute requirements," said Dan McNamara, senior vice president and general manager of Compute and Enterprise AI at AMD, in AMD's press release. McNamara stated that Helion is intended to help partners optimize rack compute to match available power budgets.

Hardware Standards and Power Constraints

Helion adheres closely to open data center specifications. According to AMD's technical brief, the system fits a 21-inch Open Rack Standard (ORv3) 44OU frame and supports both air-cooled and direct liquid-cooled (DLC) deployments. The design incorporates up to 102 Tbps of rack networking bandwidth using OCP NIC 3.0 adapters, alongside OCP Data Center Modular Hardware System (DC-MHS) compliant host processor modules, DC-SCM management modules, HPRv2 power shelves, and Caliptra silicon root-of-trust security.

The emphasis on core density per watt directly addresses severe data center power bottlenecks, as reported by The Next Web. In regions like Europe, electrical grid constraints have restricted data center development, prompting operators to prioritize the number of active agents supported per kilowatt over peak theoretical floating-point performance.

AMD Helion Rack Specifications at a Glance
• Peak CPU Density: Up to 32,768 Zen 6 cores (128 sockets)
• Processors: 6th Gen AMD EPYC 9006 Series ("Venice")
• Acceleration: Up to 16 AMD Instinct MI350P GPUs (Enterprise model)
• Network Bandwidth: Up to 102 Tbps (OCP NIC 3.0)
• Form Factor: 21-inch 44OU chassis (ORv3), air- or direct liquid-cooled
• Hardware Compliance: DC-MHS, DC-SCM, HPRv2, Caliptra root-of-trust

Availability and Ecosystem Partner Support

AMD will not manufacture or sell finished Helion server cabinets directly. Instead, the company plans to contribute the Helion specification to the Open Compute Project, allowing original equipment manufacturers (OEMs) and original design manufacturers (ODMs) to build and customize commercial products, as outlined by DataCenterDynamics.

Eight major infrastructure partners have pledged support for the Helion blueprint: Cisco, Dell Technologies, Hon Hai Technology Group (Foxconn), Hewlett Packard Enterprise (HPE), Lenovo, QCT, Supermicro, and Wiwynn, as reported by Quartz.

AMD had initially indicated that systems would ship during the first half of 2027 before revising the timeline to November 2026, coinciding with broader Zen 6 processor production ramps. AMD has not publicly disclosed pricing for Helion reference components, leaving final system pricing to hardware partners based on chosen CPU core counts, cooling loops, and GPU accelerators.

Questions people ask

What is the primary difference between AMD Helion and AMD Helios?

AMD Helios is designed for frontier-scale model training and large-scale inference using 72 tightly coupled GPUs with unified memory fabrics. In contrast, AMD Helion is a flexible rack architecture optimized for running software agents, packing up to 32,768 Zen 6 CPU cores alongside optional independent GPUs.

Can enterprises configure AMD Helion with both CPUs and GPUs?

Yes. While the hyperscale configuration is CPU-only, the enterprise configuration supports AMD EPYC CPU nodes alongside up to 16 AMD Instinct MI350P GPUs and dedicated database and storage blades.

When will AMD Helion hardware become available?

Commercial systems built on the Helion specification by manufacturing partners such as Dell, HPE, and Supermicro are scheduled to become available in November 2026.
