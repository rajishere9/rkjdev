Anthropic Donates Agent Skills Standard to Agentic AI Foundation

The transfer hands governance of the modular instruction format, domain, and brand to the Linux Foundation-backed body alongside contributions from OpenAI, Hugging Face, and Alibaba.

In short

  • Anthropic donated the Agent Skills specification, logo, GitHub organization, and agentskills.io domain to the Agentic AI Foundation (AAIF).
  • The format has reached more than 70 platforms, including ChatGPT, Cursor, GitHub Copilot, and VS Code, with 1 million skills published according to Anthropic.
  • Engineers from Anthropic, Google, and OpenAI will maintain the standard as individual contributors under lead maintainers David Soria Parra and Mahesh Murag.
  • The donation coincided with AAIF adding four projects at AGNTCon + MCPCon North America, expanding the foundation's hosted roster from three to 10 projects.

On October 22, 2026, Anthropic announced that it is donating the Agent Skills open standard to the Agentic AI Foundation (AAIF), an open-source consortium organized under the Linux Foundation. The transfer includes the Agent Skills specification, brand assets, GitHub organization, and the agentskills.io domain. The decision places future governance of the format under neutral stewardship one year after Anthropic first released skills as a product feature.

Anthropic stated in its announcement that more than 70 agent platforms have integrated Agent Skills since the format was published as an open standard in December 2025. Listed adopters include ChatGPT, Cursor, GitHub Copilot, and VS Code. Anthropic reported that developers have published approximately 1 million skills and recorded nearly 280 million installs, though explainx.ai reported that Anthropic did not release verification methodologies or deduplicated telemetry for those install counts.

This marks the second major specification Anthropic has handed to the AAIF. The company co-founded the foundation alongside Block and OpenAI in late 2025, initially donating the Model Context Protocol (MCP) to provide a shared protocol for connecting AI models to data sources and development tools.

How the Agent Skills Standard Works

Anthropic originally developed the skills framework while building Claude Code, which launched in October 2025. According to the company, large language models handled broad knowledge work effectively but struggled with procedural workflows and task-specific business logic. Rather than prompting an agent repeatedly with instructions in chat interfaces, skills package instructions into modular directories.

As documented on agentskills.io and analyzed by explainx.ai, each skill is structured as a dedicated folder containing a mandatory SKILL.md file. This core file contains required metadata with a name and description, followed by instructions telling an agent how to carry out a given operation. A skill directory can optionally include subdirectories for executable scripts, documentation references, and asset templates.

To manage context limits, the standard uses a three-tier "progressive disclosure" mechanism:

  • Startup: The host application reads only the skill's name and descriptive metadata into the agent's context window.
  • Matching: When an incoming user request aligns with a skill description, the agent ingests the complete instruction text from SKILL.md.
  • Execution: The agent runs bundled automation scripts or loads referenced files only if execution demands those resources.

While MCP supplies agents with tool connections and database access, Agent Skills specifies how tasks should be executed. SiliconANGLE observed that standardizing these procedural directories makes instructions easily portable between agent engines and reduces model hallucinations by structuring reference material uniformly.

Neutral Governance and Individual Maintainers

Under the Linux Foundation structure, contributor participation does not require membership in the AAIF. Anthropic confirmed that developers can continue to use or contribute without joining the AAIF.

Engineers will maintain the standard as individuals. David Soria Parra, an Anthropic engineer and co-creator of MCP, and Mahesh Murag will serve as Lead Maintainers. Engineers from Anthropic, Google, and OpenAI have joined the maintainer group as individuals. Writing on his blog, technologist Simon Willison noted that he personally predicted the donation to the AAIF in December 2025, when Anthropic first labeled skills an open standard.

Anthropic has proposed a three-part technical roadmap for the community under AAIF:

  1. Versioned releases: Moving away from a continuous living specification to formal versioning, replacing interim community workarounds such as custom lockfiles.
  2. Formal proposal process: Establishing a structured proposal and feedback process via GitHub and Discord for future protocol modifications.
  3. Security guidance: Publishing baseline security parameters for creators and runtimes, as skills that bundle shell scripts or code can execute with user-level permissions on host environments.

Foundation Expansion at AGNTCon

The donation of Agent Skills was one of four new project additions announced during the AGNTCon + MCPCon North America conference in San Jose, California, on October 22, 2026. According to The Linux Foundation, the new contributions expand the AAIF portfolio from three founding projects to 10 within its first operational year.

The four additions represent distinct tiers of the open agent infrastructure:

  • Agent Skills: Donated by Anthropic, governing agent procedures and operational know-how.
  • Open Responses: Donated by OpenAI, establishing a shared schema and streaming event model based on the OpenAI Responses API to simplify multi-provider application interfaces.
  • OpenEnv: Donated by Hugging Face, offering a containerized framework for reinforcement learning environments that integrates MCP with standard Gym interfaces.
  • OpenSandbox: Donated by Alibaba, providing general-purpose sandbox APIs, multi-language SDKs, and container runtimes to isolate and execute untrusted agent actions.

"Agent Skills, Open Responses, OpenEnv, and OpenSandbox each cover a different part of that stack, from how agents gain capabilities to where they run, and four different companies chose to contribute them to neutral governance," said Manik Surtani, CTO and co-founder of the Agentic AI Foundation, in The Linux Foundation's release. The four projects join preexisting AAIF repositories, including A2A, Agent Router, agentgateway, AGENTS.md, goose, and MCP.

Implications for Developers and the Agent Ecosystem

For enterprise teams and open-source contributors, the immediate file mechanics of Agent Skills remain unaltered. Skills written for compatible systems such as Claude Code, Cursor, or VS Code continue to parse identical directory trees.

However, formalizing the standard addresses key fragmentation challenges. MIXED reported that third-party vendors such as Unity have already packaged official skill extensions for coding agents, underscoring the growing reliance on common instruction standards.

Security guidance is one of the maintainers' proposed roadmap items. Because skills can package executable scripts alongside instructional text, guidance is needed because bundled scripts run with user permissions. Security researchers have previously built third-party auditing tools like NVIDIA's SkillSpector scanner, but the AAIF roadmap aims to formalize official runtime recommendations as the standard evolves under multi-company oversight.

Questions people ask

What is the Agent Skills standard?

Agent Skills is an open specification that structures specialized instructions, scripts, and documentation into a standardized folder containing a SKILL.md file, allowing AI agents to load procedural workflows on demand.

Do developers need an AAIF membership to use or create Agent Skills?

No. Anthropic confirmed that anyone can use or contribute to the standard without joining the AAIF.

How does Agent Skills differ from the Model Context Protocol (MCP)?

The Model Context Protocol connects AI agents to external data sources and tools, whereas Agent Skills provides the step-by-step instructions and procedural workflows an agent follows to complete specific tasks.

What other projects were added to the Agentic AI Foundation alongside Agent Skills?

The AAIF simultaneously accepted Open Responses from OpenAI, OpenEnv from Hugging Face, and OpenSandbox from Alibaba, expanding its hosted projects to 10.
