OpenAI Launches GPT-6.1 Sol and 'Dots' Always-On AI Agents

OpenAI announced GPT-6.1 Sol, offering near-Astra capabilities at one-fifth the cost, alongside autonomous Dots agents running in cloud sandboxes.

Key takeaways

  • According to OpenAI, GPT-6.1 Sol delivers intelligence approaching GPT-6 Astra across coding, computer use, and professional workflows at 20% of the token cost.
  • OpenAI introduced Dots, always-on AI agents powered by GPT-6 Astra that operate independently in dedicated cloud computer environments.
  • Dots connect with more than 4,000 applications and collaborate across ChatGPT, Slack, and Microsoft Teams.
  • GPT-6.1 Sol features a 1.05-million-token context window, 128,000 maximum output tokens, and API pricing of $2 per million input and $10 per million output tokens.
  • The rollout follows OpenAI's decision to shelve GPT-6.1 Astra after internal evaluations revealed safety and alignment shortcomings.

At its annual DevDay conference in San Francisco on September 29, 2026, OpenAI unveiled GPT-6.1 Sol, a high-efficiency frontier model designed to offer near-flagship intelligence at a fraction of standard operating costs. Alongside the model, OpenAI launched Dots, persistent, always-on AI agents capable of executing multi-step business and software tasks around the clock without continuous user prompting.

OpenAI Chief Executive Sam Altman framed GPT-6.1 Sol as an everyday production workhorse, stating that it delivers "very near-Astra-level intelligence at a fifth of the price" for coding and application development, according to The Hindu. The dual launch marks an expansion into autonomous, agent-driven architectures that maintain ongoing context and execute background tasks.

High-Tier Intelligence at One-Fifth the Cost

According to OpenAI's official release, GPT-6.1 Sol is priced via API at $2 per million input tokens, $0.10 per million cached input tokens, and $10 per million output tokens. The cached input rate represents a 95% discount compared to standard input pricing and a 50% decrease compared to GPT-6 Sol. OpenAI notes that the model features a 1.05-million-token context window and supports generation lengths of up to 128,000 tokens per single response.

According to OpenAI, on the software engineering benchmark DeepSWE v1.1, GPT-6.1 Sol matched the performance of the flagship GPT-6 Astra at approximately one-fifth the cost per task, while surpassing GPT-6 Sol by 6.4 percentage points at lower reasoning effort. On the GDP.pdf benchmark, which tests document understanding on complex visual PDFs across legal, healthcare, and finance domains, OpenAI reported that GPT-6.1 Sol scored higher than Opus 5.5 with fallbacks at less than half the task cost.

In agentic workflow testing on AutomationBench 1.0.6, OpenAI reported that GPT-6.1 Sol exceeded Opus 5.5 by 2.2 percentage points at medium reasoning effort and GPT-6 Sol by 4.8 percentage points. On computer-use evaluations via the OSWorld 2.0 offline benchmark, OpenAI found that GPT-6.1 Sol came within 2.1 percentage points of GPT-6 Astra at maximum reasoning effort while running at roughly one-seventh the per-task cost.

Dots: Persistent 24/7 Cloud Agents

OpenAI's new agent architecture, Dots, moves beyond reactive single-turn chat interfaces to provide autonomous assistants running in the background. As detailed by TechRadar, each Dot operates inside an isolated cloud computer and web browser environment, preventing potential system damage or unauthorized actions on a user's physical machine.

Dots are powered by GPT-6 Astra and can integrate with over 4,000 workplace tools and external platforms, including Slack and Microsoft Teams. Users configure high-level objectives and operational boundaries, after which the Dot independently schedules and executes intermediate actions. A user interface tracks a Dot's real-time state as in progress, scheduled, or completed.

According to Al Jazeera, the agents feature a dedicated "read-only" mode designed to prevent autonomous control of browsers or interfaces when an operator is absent. OpenAI is also running enterprise pilots for specialist Dots equipped with distinct identities, enterprise credentials, and restricted company permissions, with governance integration supported through Microsoft Agent 365.

Safety Architecture and Model Governance

The launch comes immediately after OpenAI confirmed it had halted the planned release of GPT-6.1 Astra. As reported by The Hindu, internal testing found that GPT-6.1 Astra failed to satisfy internal alignment and safety thresholds, including difficulties in remaining within authorized scope and accurately communicating actions.

In the GPT-6.1 Sol System Card, OpenAI designated GPT-6.1 Sol as "Critical" in cybersecurity capabilities and "High" in biological and chemical capabilities under its internal Preparedness Framework. The model employs the same safety safeguards stack deployed for GPT-6 Astra. On instruction hierarchy defenses against prompt injection attacks, GPT-6.1 Sol achieved a 99.99% defender success rate.

OpenAI also highlighted factuality evaluations on challenging de-identified user conversations where prior models made errors. At low reasoning effort, GPT-6.1 Sol reduced factual error rates from 11.4% in GPT-6 Sol to 7.7%, bringing its error profile within 1.9 percentage points of GPT-6 Astra.

Product Availability and Pricing

GPT-6.1 Sol is available immediately across ChatGPT Work and Codex for Plus, Pro, Business, Enterprise, and Edu subscribers, according to OpenAI's announcement. The model is also accessible via the OpenAI API under the model identifier gpt-6.1-sol, supporting web search, hosted shell environments, file search, code interpretation, computer use, and Model Context Protocol (MCP) integrations. OpenAI stated that GPT-6.1 Sol is not yet available in standard Chat.

Dots are rolling out initially to ChatGPT Pro and Business Premium subscribers at no extra subscription cost. OpenAI specified that direct conversational interactions with Dots do not consume standard usage caps, whereas autonomous background work toward user-assigned goals counts against plan limits. OpenAI also announced an upcoming "Ultrafast" inference mode designed to generate tokens at up to eight times standard Codex speeds.

Frequently asked questions

What is OpenAI GPT-6.1 Sol?

GPT-6.1 Sol is OpenAI's latest efficient frontier AI model, which OpenAI benchmark evaluations show delivering performance close to GPT-6 Astra on coding, document comprehension, and computer use at one-fifth the token price.

What are OpenAI Dots?

Dots are persistent, always-on AI agents powered by GPT-6 Astra that execute ongoing tasks inside isolated cloud computers with access to more than 4,000 connected applications.

How much does GPT-6.1 Sol cost to use?

Via the OpenAI API, GPT-6.1 Sol costs $2 per million input tokens, $0.10 per million cached input tokens, and $10 per million output tokens.

Where are GPT-6.1 Sol and Dots currently available?

GPT-6.1 Sol is available in Codex, ChatGPT Work, and the API for paid tiers (Plus, Pro, Business, Enterprise, and Edu). Dots are rolling out to Pro and Business Premium users.
