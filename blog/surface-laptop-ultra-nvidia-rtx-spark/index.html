Microsoft Debuts $2,599 Surface Laptop Ultra With NVIDIA RTX Spark

Microsoft and NVIDIA partnered on new Arm-based hardware and Windows 11 system containers built to run 120-billion-parameter AI models locally.

Key takeaways

  • The Surface Laptop Ultra starts at $2,599 with preorders open immediately and shipments beginning on October 16, 2026.
  • Powered by NVIDIA RTX Spark, the laptop combines an Arm-based Grace CPU and a Blackwell GPU with up to 128GB of unified memory and one petaflop of FP4 AI compute.
  • Windows 11 introduces Microsoft Execution Containers and Hybrid Intelligence to run persistent AI agents securely without sending local files to the cloud.
  • Microsoft also introduced the $5,999 Surface RTX Spark Dev Box mini PC shipping in November 2026, alongside previews of the NVIDIA DGX Station for Windows.

Microsoft announced the Surface Laptop Ultra on October 7, 2026, marking the hardware debut of NVIDIA's RTX Spark platform for Windows PCs. Unveiled during a joint presentation at Dogpatch Studios in San Francisco, the flagship notebook carries a $2,599 starting price and is built to run large artificial intelligence models entirely on-device. The launch was framed by Microsoft Chief Executive Officer Satya Nadella and NVIDIA founder Jensen Huang as an architectural shift toward local AI agents, combining custom silicon, unified memory, and containerized security directly inside the Windows operating system, according to NVIDIA's official announcement.

Preorders opened immediately following the keynote, with the laptop scheduled to begin shipping on October 16, 2026. The announcement was accompanied by a broader ecosystem rollout, including mini PCs from Microsoft and third-party systems from hardware partners such as Dell, HP, Lenovo, and ASUS.

Surface Laptop Ultra Specs and Hardware Design

Microsoft claimed the Surface Laptop Ultra was the most powerful Surface Laptop ever, aimed directly at professional developers and technical workstations. According to reporting from The Verge, the notebook features a 15-inch HDR touchscreen capable of reaching 2,000 nits of peak brightness, paired with an enlarged haptic trackpad and an aluminum chassis. In a hands-on review, Engadget reported the machine weighs under 4.5 pounds, positioning it as lighter than Apple's 16-inch MacBook Pro.

For connectivity, the device includes full-sized SD card storage, HDMI, and multiple USB-C ports. Microsoft also introduced a magnetic charging mechanism called Magnetic Connect. Rather than reviving the older Surface Connect slot, Microsoft engineered a magnetic breakaway cable that latches directly to an offset USB-C port on the side of the chassis, as documented by The Verge. Standard USB-C power supplies can still charge the laptop through that same port.

Under the hood, base specifications start with 24GB of unified memory and 512GB of solid-state storage. Sources note slight variations in CPU core descriptions for the base tier, with early configuration summaries citing an 8-core CPU while detailed spec listings describe an 18-core arrangement, as reported by The Verge. High-end tiers scale up to 128GB of unified memory and configurations reaching $5,900, according to TechCrunch.

NVIDIA RTX Spark and the Move to Unified Arm Architecture

The technological engine inside the Surface Laptop Ultra is RTX Spark, NVIDIA's platform designed to bring its full computing stack to Arm-based Windows systems. As detailed by NVIDIA, the RTX Spark superchip links an NVIDIA Blackwell RTX GPU featuring up to 6,144 cores with an NVIDIA Grace CPU containing up to 20 cores over an interconnect transferring data at 600 gigabytes per second.

The architecture provides up to 128GB of coherent unified memory and delivers one petaflop of FP4 AI performance. NVIDIA stated that this density enables systems to run local models such as Qwen 3.8 Flash Next—a 125-billion-parameter model with a 51-billion n-gram structure—entirely on the device without routing private data through external cloud servers. Because the hardware shares the standard CUDA development platform, engineers can move code across RTX Spark laptops up to data center hardware without rewriting pipelines.

Beyond specialized machine learning, the hardware includes fifth-generation Tensor Cores with NVFP4 precision support, hardware-accelerated AV1, and 4:2:2 video encode and decode. In gaming demonstrations, the platform supported titles like Gears of War: E-Day smoothly at slightly more than 1080p while running on battery power, according to Engadget. NVIDIA reported that the platform supports 1440p gaming at over 100 frames per second with DLSS 5, Reflex, and G-SYNC.

Windows 11 Adds Execution Containers and Hybrid Intelligence

To support autonomous programs running in the background, Microsoft introduced structural updates to Windows 11 during the event. Pavan Davuluri, Microsoft's executive vice president of Windows and Devices, announced the general availability of Microsoft Execution Containers (MXC). According to coverage by Tom's Hardware, MXC acts as an operating-system-level sandbox where background software agents execute persistently under strict OS observation and security controls.

Microsoft also introduced Hybrid Intelligence, a framework designed to split computing between local chips and cloud datacenters. As outlined by Engadget, the system directs sensitive or cost-prohibitive prompts to local models while routing heavier tasks to external servers. During the keynote, Microsoft demonstrated its personal AI agent Autopilot organizing an employee's tax documents: an on-device model located relevant forms across system folders, zipped the archive, and drafted an email to an accountant without transmitting financial records over the internet.

Windows Search is also receiving an interactive overhaul arriving in fall 2026. The revised interface turns the taskbar into a command bar capable of adjusting system settings—such as triggering dark mode or volume sliders—and messaging phone contacts via direct prompt inputs, as detailed by Engadget. Davuluri also confirmed that Meta will launch a native Windows application for its Muse AI agent.

Surface RTX Spark Dev Box and Enterprise DGX Station

Alongside the mobile hardware, Microsoft announced desktop hardware geared toward sustained operations. The Surface RTX Spark Dev Box is a compact desktop mini PC available for preorder at $5,999, slated to ship in November 2026, according to The Verge. Featuring a 3D-printed anodized aluminum chassis with a 100-watt thermal profile, the Dev Box includes 128GB of unified memory and comes preinstalled with Windows 11 Pro, Visual Studio Code, Git, WSL, Python, Node, and GitHub Copilot CLI under Microsoft's Project Zenith initiative.

For enterprise customers, the presentation previewed the NVIDIA DGX Station for Windows. Described by NVIDIA as a deskside supercomputer, the station utilizes the GB300 Grace Blackwell Ultra Desktop Superchip. It offers 748GB of coherent memory and delivers up to 20 petaFLOPS of FP4 performance, allowing enterprise teams to run models containing up to one trillion parameters locally while retaining native access to Windows productivity software.

Pricing, Trade-Ins, and Availability

Preorders for the Surface Laptop Ultra are open now starting at $2,599, with general retail availability scheduled for October 16, 2026. Secondary configurations equipped with higher-tier chips start at $3,700 and peak at $5,900, with Microsoft stating that the highest-end device was already out of stock, according to TechCrunch.

To persuade developers migrating from alternative Unix-based portable systems, Microsoft is providing trade-in incentives of up to $1,000 for Apple MacBook Pro devices, as reported by TechCrunch. Partner machines are entering the market simultaneously; Dell announced its XPS 16 Creator Edition running on RTX Spark for $3,800, available for late October delivery, while compact desktops from Acer, ASUS, HP, Lenovo, MSI, and Gigabyte will arrive in November.

How much does the Surface Laptop Ultra cost and when does it ship?

What processor powers the Surface Laptop Ultra?

The laptop runs on NVIDIA's RTX Spark platform, which pairs an Arm-based Grace CPU with a Blackwell GPU featuring up to 6,144 cores, up to 128GB of unified memory, and one petaflop of FP4 AI performance.

What is the Surface RTX Spark Dev Box?

The Dev Box is a $5,999 developer mini PC featuring 128GB of unified memory, a 100-watt thermal envelope, and preinstalled software tools like VS Code, WSL, and Python, scheduled to ship in November 2026.

What new local AI capabilities does Windows 11 include?

Windows 11 introduces Microsoft Execution Containers (MXC) for isolated agent execution, a taskbar chatbot in Windows Search, and Hybrid Intelligence, which processes sensitive data locally without uploading it to cloud servers.
