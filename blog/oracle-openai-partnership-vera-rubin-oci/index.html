Oracle Expands OpenAI Partnership and Unveils Vera Rubin on OCI

The enterprise cloud provider integrates ChatGPT across its application suite and plans multi-gigawatt deployments of NVIDIA and Google silicon, while deployment capacity for Cerebras was not specified.

In short

  • Oracle launched four new enterprise software offerings developed with OpenAI: Oracle AI Workspace, Oracle AI Security Mesh, Oracle App Composer, and an SMB bundle.
  • NVIDIA Vera Rubin NVL72 rack-scale systems and standalone Vera CPUs have reached general availability on Oracle Cloud Infrastructure (OCI).
  • OCI will become the first external hyperscaler to host Google TPUs (TPU 8t and 8i), with multi-gigawatt rollouts starting in 2027 alongside Cerebras Wafer-Scale inference systems.
  • Oracle reported 850 megawatts of data center capacity and more than 300,000 GPUs added during fiscal Q1 2027, with remaining performance obligations hitting $664 billion.

On October 27, 2026, at Oracle AI World in Las Vegas, Oracle announced a comprehensive expansion of its artificial intelligence portfolio spanning enterprise software and high-density compute. The company unveiled an expanded partnership with OpenAI to integrate models directly into Oracle's business suite, while simultaneously broadening Oracle Cloud Infrastructure (OCI) with new compute architectures including NVIDIA Vera Rubin systems, Google TPUs, and Cerebras wafer-scale processors.

According to Oracle's corporate announcement, the software collaboration focuses on bringing generative and agent-based AI directly into daily enterprise operations. In a statement, Oracle CEO Clay Magouyrk said the initiative unites OpenAI's capabilities with the "Oracle applications, data, and cloud infrastructure" that enterprises depend on for core operations. OpenAI President and Co-founder Greg Brockman noted that the tie-up helps organizations "build software faster, strengthen security and take on more complex knowledge work."

Bringing ChatGPT and Codex into Enterprise Operations

The software collaboration introduces four core offerings targeting different business roles: Oracle AI Workspace, Oracle AI Security Mesh, Oracle App Composer, and the Oracle AI SMB Bundle.

Oracle AI Workspace acts as a unified hub connecting OpenAI models with Oracle Fusion Applications, Oracle NetSuite, Oracle AI Database, and underlying OCI services. As detailed by OpenAI, the workspace is designed to allow workers to trigger approved workflows and query records in plain English through ChatGPT. For example, a finance employee can use ChatGPT to examine cost allocations, analyze purchasing records, and resolve closing items prior to a month-end close. OpenAI reported that Oracle itself has reached 130,000 active ChatGPT users and over 95,000 active Codex users internally, noting its recruiting staff reduced market research preparation from several days down to 15 to 20 minutes.

For custom development, Unite.AI reported that Oracle App Composer allows teams to generate internal software using Codex without manual coding. Currently in limited availability, the platform provisions resources directly on OCI, connecting to OCI Kubernetes Engine and Oracle Autonomous AI Database while enforcing corporate identity and audit controls. It also supports APEXlang, a proprietary Oracle technology designed to accelerate generative software development without producing unmaintainable code.

To reach early-stage companies, Oracle introduced the Oracle AI SMB Bundle, offering up to $12,000 annually in OCI credits for up to three years. The package pairs ChatGPT Business, Codex, and App Composer with NetSuite QuickStart for basic invoicing and accounting. Oracle restricted eligibility to independent, privately held U.S. businesses with under $250,000 in prior Oracle credit usage, excluding crypto enterprises, service-only consultancies, and government units.

Automated Vulnerability Defense with AI Security Mesh

Addressing cybersecurity risks, the companies introduced Oracle AI Security Mesh. This managed service uses OpenAI cyber models to proactively identify and remediate vulnerabilities across OCI, on-premises environments, and rival clouds before malicious actors exploit them.

Under this workflow, Oracle outlines the customer's attack surface and presents a test plan for administrative approval. Specialized agents analyze software weak points and verify exploitable pathways, while secondary agents rerun tests independently to confirm issues are real rather than false positives. Coding agents then supply proposed software patches for human review. Oracle stated that findings are saved exclusively to the customer's private knowledge repository to refine subsequent audits while minimizing downtime risks.

Beyond application integration, U.S. customers can now purchase access to the OpenAI API, Codex, and ChatGPT Work directly on the Oracle Marketplace using existing Universal Credits agreements.

OCI Deploys NVIDIA Vera Rubin and Standalone Vera CPUs

On the hardware front, Oracle revealed that NVIDIA Vera Rubin NVL72 rack-scale systems and NVIDIA Vera CPUs have attained general availability on OCI. According to DataCenterDynamics, Oracle plans to scale these Vera Rubin architectures across multi-gigawatt OCI Superclusters, building on its previous deployment of over 100,000 Blackwell GPUs used by OpenAI in Abilene to train GPT-6 Astra.

Each Vera Rubin NVL72 rack links 72 GPUs over NVIDIA NVLink, paired with NVIDIA Spectrum-X Ethernet featuring Spectrum-6 switches and BlueField-4 data processing units (DPUs). Sreekanth Pothanis, compute infrastructure engineering lead at OpenAI, said Vera Rubin on OCI supplies the computing scale required to serve demanding frontier workloads. OpenAI also plans to run NVIDIA's standalone Vera CPUs in production on OCI to handle orchestration, tool execution, and code processing for agentic workloads.

Oracle confirmed it will subsequently introduce NVIDIA HGX Rubin NVL8 configurations, combining eight Rubin GPUs with dual 64-core Intel Xeon 6 processors, 4TB of DDR5 memory, and 6.4 Tbps high-speed RDMA networking, as outlined by Seeking Alpha.

Diversifying Silicon: Google TPUs, Cerebras, and Custom Chips

Rather than relying solely on a single hardware vendor, Oracle is opening OCI to alternative processing architectures. Writing on Oracle's corporate blog, Karan Batta, senior vice president of product for OCI, confirmed that Oracle will become the first external hyperscale provider to offer Google TPUs.

Under a multi-gigawatt agreement, Oracle will deploy Google's eighth-generation accelerators starting in 2027, offering TPU 8t for large-scale model training and TPU 8i for inference. Furthermore, Oracle plans to deploy Cerebras Wafer-Scale Engine systems in 2027 to lower per-token latency for reasoning tasks. Andrew Feldman, CEO and co-founder of Cerebras, noted that minimizing token generation latency is vital because multi-step AI agents repeatedly verify logic and invoke software tools.

Oracle's compute lineup is also expanding across general-purpose and custom architectures:

  • Intel Collaboration: A multi-year roadmap extending Intel Xeon compute to future OCI X14 instances powered by Diamond Rapids processors, incorporating Advanced Matrix Extensions (AMX) for FP8, FP16, and BF16 inference alongside Advanced Performance Extensions (APX).
  • AMD Compute E7 Instances: Upcoming servers powered by 6th Gen AMD EPYC 9006 processors supporting up to 256 cores, 1,024 MB of L3 cache, PCIe 6.0, and AMD Pensando DPUs.
  • Specialized Accelerators: Immediate general availability of Intel-fabricated Positron Atlas inference chips, upcoming deployments of SambaNova SN50 hardware, and plans to host OpenAI's proprietary Jalapeño inference accelerators developed with Broadcom.

Network Fabric and Datacenter Expansion

To manage these compute clusters, Oracle unveiled enhancements to its Oracle Acceleron networking fabric. Originally introduced in 2025, Acceleron has been upgraded with front-end RDMA connectivity, an automated Collective Communications Library to steer traffic away from degraded hardware pathways, and multiplanar networking that provides automated path selection and congestion control.

According to Converge Digest, the physical scale underpinning these services expanded substantially during the first quarter of fiscal 2027. Oracle added 850 megawatts of operational data center capacity and deployed more than 300,000 GPUs during the quarter. OCI cloud infrastructure revenue reached $7.4 billion—up 121 percent year over year—while total remaining performance obligations climbed to $664 billion.

By uniting enterprise database tools and OpenAI models on top of a multi-vendor hardware ecosystem, Oracle is positioning its cloud infrastructure to support both frontier model research and day-to-day enterprise agent workloads.

Questions people ask

What software tools did Oracle and OpenAI launch together?

Oracle and OpenAI introduced four products: Oracle AI Workspace for running Oracle workflows through ChatGPT, Oracle AI Security Mesh for identifying infrastructure vulnerabilities, Oracle App Composer for building software with Codex, and the Oracle AI SMB Bundle for small businesses.

Which new chips are entering Oracle Cloud Infrastructure?

NVIDIA Vera Rubin NVL72 systems, standalone Vera CPUs, and Positron Atlas chips are now generally available. Google TPU 8t and 8i processors, Cerebras Wafer-Scale engines, and Intel Diamond Rapids processors are scheduled to follow in 2027 and beyond.

Who is eligible for the Oracle AI SMB Bundle?

The package is open to independent, for-profit U.S. businesses that have used less than $250,000 in Oracle Universal Credits. It provides $12,000 per year in cloud credits for up to three years alongside access to ChatGPT Business, Codex, and NetSuite QuickStart.
