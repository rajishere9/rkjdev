OpenAI Frontier Models and Codex Launch on Google Cloud Model Garden

Enterprise customers can run GPT-6 Astra, Sol, and Luna alongside Google Cloud services and draw down existing spend commitments.

In short

  • OpenAI is bringing its GPT-6 Astra, GPT-6.1 Sol, and GPT-6 Luna models, along with Codex agentic workflows, to Google Cloud's Model Garden.
  • Enterprise customers can purchase access through Google Cloud Marketplace and draw down existing Google Cloud spending commitments.
  • The models are rolling out in private preview, with general availability planned in the coming weeks and future support slated for Google Antigravity and Gemini Agent.
  • Google Cloud claims it is now the only hyperscale cloud provider offering access to all three leading closed-source large language models.

OpenAI and Google Cloud announced an agreement on October 21, 2026, to bring OpenAI's flagship artificial intelligence models and Codex agentic workflows to Google Cloud's Model Garden. The collaboration allows enterprise customers to run OpenAI's newest systems directly within Google Cloud's managed environment, transacted through the Google Cloud Marketplace.

According to an announcement by OpenAI, general availability is scheduled for the coming weeks, while Microsoft remains OpenAI's primary cloud partner. The integration expands access to OpenAI technology across major cloud platforms, making Google Cloud the latest infrastructure provider to natively host the lab's proprietary software.

What Models Are Coming to Model Garden

Under the partnership, Google Cloud is adding three of OpenAI's newest models to its Model Garden catalog: GPT-6 Astra, GPT-6.1 Sol, and GPT-6 Luna. As detailed by Google Cloud, these systems are currently rolling out in private preview to select enterprise customers.

GPT-6 Astra serves as the flagship tier designed for demanding assignments across coding, computer use, professional workflows, and scientific research. According to reporting from SiliconANGLE, Astra was responsible for several AI-generated mathematics discoveries published in recent weeks and achieved a perfect score on ExploitBench, a benchmark evaluating an AI model's ability to discover and exploit cybersecurity flaws. OpenAI claims Astra produces fewer misaligned outcomes than other frontier models it has evaluated and is configured to respect user-defined task restrictions.

The two companion models provide lower-cost alternatives. GPT-6.1 Sol delivers near-Astra intelligence across agentic coding and professional tasks at five times lower cost than Astra, while GPT-6 Luna operates as a lightweight option for high-volume tasks at 100 times lower cost than Astra, SiliconANGLE reported.

Integration Across Google Cloud and Developer Tools

In addition to API access in Model Garden, OpenAI models are slated to integrate across Google's developer and workflow products. Google Cloud announced that developers can immediately connect their local Codex CLI and Desktop environments directly to the Gemini platform for inference.

Coming soon, the models will also be supported inside Google Antigravity—a development tool that utilizes agent ensembles—and within the Gemini Agent environment designed to automate cross-application workflows, according to 9to5Google. Antigravity already supports Anthropic's Claude models alongside Google's native Gemini models.

For enterprise customers, the integration is governed by Google Cloud's security controls. Google stated that prompts, context, and completions will remain inside designated customer data perimeters and will not be used to train foundation models, with Zero Data Retention options arriving soon. Workloads run on dedicated Google Cloud infrastructure routed through hardened gateways, with integration into Google's Confidential Compute portfolio—using hardware-level Trusted Execution Environments—planned for a future release.

Pricing, Procurement, and Cloud Market Strategy

Procurement is handled through the Google Cloud Marketplace. Enterprises with existing Google Cloud spend commitments can apply those balances toward OpenAI model usage, and purchases will count toward Flexible Savings Plans, according to Google Cloud. This eliminates the need for organizations to establish separate billing accounts or independent vendor contracts.

"We are focused on giving customers a broad selection of models, including those from OpenAI, so they can choose the right model for any given job, helping to deliver optimal quality and lower costs," said Google Cloud Chief Executive Thomas Kurian, in statements cited by SiliconANGLE. Google Cloud stated it is now the only hyperscale cloud provider offering access to all three leading closed-source large language models on a single platform.

The agreement marks another expansion in OpenAI's cloud distribution strategy. As reported by Quartz, OpenAI launched a limited-preview integration on Amazon Web Services' Bedrock platform in April 2026 after renegotiating terms with Microsoft that capped revenue-share obligations and allowed third-party platform distribution. With Google Cloud onboard, OpenAI models are now available across Microsoft Azure, AWS, and Google Cloud, while OpenAI continues to operate ChatGPT and its own developer API partly on Google infrastructure.

Questions people ask

Which OpenAI models are being made available on Google Cloud?

Google Cloud is adding GPT-6 Astra, GPT-6.1 Sol, and GPT-6 Luna, alongside Codex agentic workflows, to its Model Garden service.

Can existing Google Cloud commitments be used to purchase OpenAI models?

Yes. Enterprises can purchase model usage through Google Cloud Marketplace, drawing down existing cloud spending commitments and applying usage to Flexible Savings Plans.

When will OpenAI models be generally available on Google Cloud?

The models are currently available in private preview to select enterprise customers, with general availability scheduled in the coming weeks.

Does this deal replace OpenAI's partnership with Microsoft?

No. OpenAI confirmed that Microsoft remains its primary cloud partner.
