Moonshot AI Releases Kimi K3.1 Pro With Open Weights Set for November

The Chinese AI lab introduces Kimi K3.1 Pro, which Moonshot AI reports in its technical announcement posted competitive scores across coding benchmarks while deliberately pruning offensive cyber capabilities ahead of an open-weight release.

In short

  • Moonshot AI has launched Kimi K3.1 Pro and a faster Highspeed variant across its apps and API, with full open weights scheduled for publication by November 4, 2026.
  • The 3-trillion-class model features a 1-million-token context window and achieved 55 points on the Artificial Analysis Intelligence Index, landing fourth behind top closed proprietary models.
  • On Terminal-Bench 4.0, Moonshot AI self-reported that K3.1 Pro scored 65.7% (not independently verified), trailing Claude Opus 5.5 (66.4%) and outpacing GPT-6 Astra (58.2%).
  • Moonshot AI states that it intentionally removed cyberattack data from training, reducing in-house vulnerability-exploitation benchmark scores from 90.5% to 81.0% to mitigate open-weight security risks.
  • Hosted API pricing is set at $2.00 per million input tokens and $10.00 per million output tokens, representing a 33% reduction from Kimi K3.

Moonshot AI has unveiled Kimi K3.1 Pro, an upgraded post-trained model built on its 3-trillion-class architecture, alongside a faster companion variant called Kimi K3.1 Pro Highspeed. The release, announced via an official technical blog post, brings a 1-million-token context window and major updates to coding, 3D spatial design, and financial analysis. While the model is accessible immediately through Moonshot AI's consumer apps, desktop software, and developer API, the company announced that full model weights will be released publicly by November 4, 2026.

The launch immediately narrows the documented performance spread between open-weight architectures and top-tier closed proprietary systems. Independent evaluation firm Artificial Analysis placed K3.1 Pro at 55 points on its Intelligence Index, according to The Decoder. That score positions K3.1 Pro in fourth place globally, trailing Claude Opus 5.5 at 58 points, and Claude Sonnet 5.5 and Muse Wonder Full at 56 points, while matching or exceeding frontier offerings from OpenAI and Google.

Post-Training Architecture and Compute Scaling

Kimi K3.1 Pro is not an entirely new foundational model from scratch; rather, it is a post-trained iteration of Kimi K3, which initially debuted in July 2026. According to The Decoder, the system retains the structural dimensions of K3, maintaining approximately 2.8 trillion total parameters with 104 billion active parameters.

To build K3.1 Pro, Moonshot AI applied substantially increased post-training compute. The company reported that it revamped its reinforcement learning (RL) framework, long-context inference runtime, distributed training efficiency, execution sandbox infrastructure, rollout scheduling, and automated environment evaluation. This unified infrastructure was tuned to support joint reinforcement learning across hundreds of downstream domains simultaneously, ensuring that ongoing compute scaling produced predictable capability improvements.

Alongside the base model, Moonshot AI launched Kimi K3.1 Pro Highspeed. As detailed in the Kimi Code documentation, the Highspeed edition retains identical underlying reasoning capabilities while delivering two to three times the generation speed of standard K3.1 Pro, in exchange for roughly double the quota consumption.

Benchmark Performance in Coding, 3D, and Finance

In synthetic tests and realistic agent evaluations, Moonshot AI reported marks that place K3.1 Pro alongside premier proprietary systems. On Terminal-Bench 4.0—an evaluation testing coding agents on realistic terminal tasks under resource constraints—K3.1 Pro achieved 65.7% using the Claude Code harness, according to Moonshot AI's technical blog and explainx.ai. That mark places the model narrowly behind Anthropic's Claude Opus 5.5 (66.4%) and ahead of OpenAI's GPT-6 Astra (58.2%).

On internal coding assessments, Moonshot reported a score of 61.2% on Kimi Code Bench 3.0 Long-horizon, up from 55.95% on Kimi K3. In a demonstration of extended agentic problem solving cited by Unite.AI, the model was tasked with building a bipedal walking dynamics simulator on top of human-atlas, an anatomical model comprising 296 skeletal components and 402 muscles. Operating across 167 missions and 420 independent evaluation reviews, K3.1 Pro diagnosed dynamic imbalances in the walking controller. When standard reward shaping failed to correct erratic arm motion, the model executed open-loop probes of the physics simulator, identified 36 mathematical errors in shoulder-muscle moment-arm calculations, corrected them, and trained the simulation to walk stably for 11.2 seconds.

Beyond software development, the model shows improvements in spatial generation and fiscal research:

  • 3D Design: On BenchCAD, which evaluates multi-view 3D reconstruction into CAD instructions, Moonshot AI reported that K3.1 Pro achieved 92.7% with tools (compared to 96.2% for Claude Opus 5.5 and 95.9% for GPT-6 Astra). According to Moonshot AI's technical report, it can script CAD engines and Blender directly without Model Context Protocol connectors.
  • Financial Workflows: Moonshot reported a state-of-the-art score of 64.4 on OfficeQA Pro v2, a test measuring numerical synthesis across complex corporate documents. On internal benchmarks, the model posted gains of 7.2 points in financial modeling, 11.6 points in financial research, and roughly 4.2 times K3's score on long-horizon business operation simulations.
  • Reduced Hallucinations: On Kimi Hallu Bench Hard, Moonshot's internal stress test designed to induce factual errors, the claim-level hallucination rate declined from 23.4% on K3 to 8.3% on K3.1 Pro.

Deliberate Cybersecurity Filtering

One of the most consequential decisions detailed in the technical disclosure involves Moonshot AI's handling of offensive cyber capabilities. Post-training scaling naturally improved the model's capacity to identify software vulnerabilities and construct functional exploits, as security-related discussions and tasks were embedded across the general mid-training corpus and reinforcement learning environments.

Because open-weight models cannot be recalled, modified, or gated once weights are distributed publicly, Moonshot chose to systematically scrub cyberattack-related data from both mid-training corpora and downstream RL environments. To measure the impact, the team ran evaluations on xdev-bench-hard, an in-house suite reproducing recently disclosed software flaws across targets like the Linux kernel, Node.js, JavaScriptCore, and Exim.

A checkpoint trained without safety interventions solved 90.5% of exploit tasks at pass@3. Following data sanitization, the production K3.1 Pro solved 81.0%. While this marks an intentional downgrade compared to what the raw training pipeline could generate, it remains substantially higher than Kimi K3's 33.3% score. Moonshot noted that general improvements in debugging and code synthesis naturally transferred to cyber tasks even after targeted scrubbing.

Moonshot stated two principles guiding its open-weight releases: first, avoid publishing weights that push the absolute frontier of offensive cyber utility beyond that of known proprietary models; second, progressively elevate open defense capabilities so external developers can run audits on legacy codebases using hardware they fully control.

Developer Access, Pricing, and Availability

Kimi K3.1 Pro and K3.1 Pro Highspeed are live across consumer, developer, and enterprise tiers. Software clients include web access at Kimi.ai, mobile apps across iOS, Android, and HarmonyOS, and desktop applications for Windows and Apple silicon Macs on Kimi Work version 3.1.0 or higher.

Developers using Kimi Code can activate the system with the /model command. As noted in official documentation, K3.1 Pro operates exclusively in reasoning mode; sending API calls with thinking disabled results in an HTTP 400 rejection. The models accept reasoning_effort parameters configured to low, high, or max, with max set as the default.

Hosted API pricing via the Kimi API Platform drops standard token costs by 33% compared to K3:

  • Standard K3.1 Pro: $2.00 per million input tokens, $10.00 per million output tokens, and $0.20 per million cached input tokens.
  • K3.1 Pro Highspeed: $4.00 per million input tokens, $20.00 per million output tokens, and $0.20 per million cached input tokens.

For enterprise deployments, access remains toggled off by default and requires administrative activation. Moonshot AI also provides Zero Data Retention policies for API customers. The broader open-source community will be able to audit and run the weights locally once the scheduled publication window concludes on November 4, 2026.

Questions people ask

When will the open weights for Kimi K3.1 Pro be released?

Moonshot AI announced that the full model weights will be released publicly by November 4, 2026.

How does Kimi K3.1 Pro compare to Claude Opus 5.5 and GPT-6 Astra?

On the coding benchmark Terminal-Bench 4.0, Moonshot reported that K3.1 Pro scored 65.7%, placing it ahead of GPT-6 Astra (58.2%) and slightly behind Claude Opus 5.5 (66.4%). On the Artificial Analysis Intelligence Index, K3.1 Pro scored 55 points, ranking fourth overall.

Why did Moonshot AI remove cybersecurity data from Kimi K3.1 Pro?

Because open weights cannot be modified once downloaded, Moonshot filtered cyberattack material from mid-training and reinforcement learning to prevent the model from expanding the frontier of offensive hacking capabilities, lowering its score on an internal vulnerability exploit benchmark from 90.5% to 81.0%.

How much does the Kimi K3.1 Pro API cost?

Standard Kimi K3.1 Pro is priced at $2.00 per million input tokens and $10.00 per million output tokens, with cache hits billed at $0.20 per million tokens. The Highspeed variant is priced at $4.00 for input and $20.00 for output.
