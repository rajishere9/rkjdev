Nanbeige Releases Nanbeige4.3-33B Open Agentic Coding Model

The Chinese lab backed by BOSS Zhipin launches an open-weight 33B model designed for autonomous coding and office agents, featuring a 524,288-token context window.

In short

  • Nanbeige released Nanbeige4.3-33B on October 24, 2026, under an Apache 2.0 license with a 524,288-token context window.
  • The 33.1-billion parameter dense model is designed as a teacher model to distill future smaller variants like Nanbeige4.3-3B.
  • Self-reported benchmarks claim strong leads on Terminal-Bench 2.1 (80.9) and DeepSWE (65.5), though it trailed Qwen3.8-27B on SWE-Bench Pro.
  • Community quantization group AtomicChat released GGUF builds on October 25, 2026, noting the architecture is sensitive to sub-4-bit quantization.

On October 24, 2026, Chinese artificial intelligence laboratory Nanbeige released Nanbeige4.3-33B on Hugging Face, an open-weight model licensed under Apache 2.0 and tailored for autonomous coding and multi-step cowork workflows. Built on a dense architecture with approximately 33.1 billion parameters in BF16 precision, the release introduces a native context window of 524,288 tokens (512K) and ships with reasoning activated by default. The lab, backed by Chinese recruitment platform BOSS Zhipin, positions the release as a capable agentic engine intended to serve as a teacher model for smaller upcoming derivatives.

The launch immediately drew interest from developers looking to run agentic coding tasks without paying managed API rates or running hundreds of billions of parameters. On October 25, 2026, community maintainers at AtomicChat published GGUF quantized weights, enabling developers to evaluate the model on local workstations and individual high-memory cards.

Architecture and Teacher Distillation Strategy

According to the official Nanbeige4.3-33B model card, the release acts as the flagship anchor for the Nanbeige4.3 series. The lab's stated design philosophy is to train a high-capacity teacher agent first, collecting execution trajectories and reasoning outputs to distill into compact edge models later. Nanbeige previously published smaller on-device models, including Nanbeige4.1-3B and Nanbeige4.2-3B, and plans to release Nanbeige4.3-3B as the distilled student model using this 33B foundation.

The model features a Llama-style tag and runs in BF16 across approximately 66 gigabytes on disk. In contrast to multimodal models such as Google's Gemma 4 31B, Nanbeige4.3-33B is strictly text-based, supporting English and Chinese. Nanbeige has not disclosed training dataset compositions, compute cluster details, or token counts, keeping the underlying data recipe private as reported by explainx.ai.

Agentic Coding and Cowork Benchmarks

Nanbeige reported detailed benchmark evaluations comparing Nanbeige4.3-33B against three comparable open models in the ~30B parameter bracket: Alibaba's Qwen3.8-27B, Muse-Glimmer-30B, and Gemma 4 31B. All models were tested at their highest thinking effort using identical harnesses per benchmark. As detailed on Startup Fortune, the self-reported scores show significant margins in long-horizon terminal and software engineering environments.

On agentic coding, Nanbeige4.3-33B achieved an 80.9 on Terminal-Bench 2.1 (evaluated with Terminus 2), surpassing Qwen3.8-27B (73.0), Muse-Glimmer-30B (61.8), and Gemma 4 31B (47.2). On Terminal-Bench 4.0 using mini-swe-agent v2.4.6, Nanbeige scored 23.8 compared to Qwen's 6.3, while Muse-Glimmer-30B scored 1.6 and Gemma scored 0.0. On DeepSWE, Nanbeige posted 65.5 against Qwen's 42.5. However, the model did not post a clean sweep: Qwen3.8-27B led on SWE-Bench Pro with 61.7 versus Nanbeige's 60.3.

In agentic cowork benchmarks, Nanbeige4.3-33B scored 54.2 on Automation Bench v1.0.6 (outperforming Qwen's 38.3) and 44.8 on JobBench (ahead of Qwen's 34.5). On YC-bench, a long-horizon enterprise simulation scored in simulated dollars, Nanbeige reported $1,025,437 compared to Qwen3.8-27B's $641,290. On GDPval, however, Qwen retained a lead at 86.4 over Nanbeige's 84.8. Pure reasoning tasks yielded tight results: Nanbeige posted 95.2 on AIME 2026 against Qwen's 94.5, while trailing Gemma 4 31B on GPQA Diamond (89.5 to 91.3), as noted in coverage by AI Weekly.

Evaluation Caveats and Testing Context

Independent analysts have urged caution regarding the headline figures. Analysis from OrcaRouter highlighted that Gemma 4 31B's score of 0.0 on Terminal-Bench 4.0 and 2.7 on DeepSWE likely reflects tool harness incompatibility rather than baseline capability. The evaluations used mini-swe-agent v2.4.6 and Terminus 2 tuned for XML tool syntax, which aligns with Nanbeige's default configuration but may not support competing chat templates.

Furthermore, discrepancies exist between reported scores and third-party published documentation. While Nanbeige credited Gemma 4 31B with 91.3 on GPQA Diamond, Google's official model documentation lists 84.3 for Gemma 4 31B. Independent tracking platforms like Artificial Analysis do not list Nanbeige4.3-33B, meaning all current performance metrics stem solely from Nanbeige's repository.

Inference Settings and Local Deployment

For teams deploying the model, Nanbeige provides specific chat template toggles in its official release repository:

  • enable_thinking: Set to True by default; toggles chain-of-thought generation.
  • preserve_thinking: Keeps reasoning traces from prior turns in multi-turn dialogues. Nanbeige recommends setting this to True for agentic coding and multi-turn tool calling, and False for general chat.
  • Tool formats: Supports both XML and JSON formats, with XML explicitly recommended for higher accuracy.
  • Recommended sampling: Temperature 1.0, top-p 0.95, and up to 65,536 max tokens for tool-use tasks; temperature 0.6, top-p 0.95, and up to 262,144 max tokens for reasoning.

Official serving instructions target SGLang and vLLM runtimes, specifying four-way tensor parallelism (--tp-size 4) and requiring the qwen3_coder tool parser. Because loading the model in Transformers requires trust_remote_code=True, users must execute code packaged directly in the model repository.

For local execution, AtomicChat's GGUF repository offers quantized files ranging from 13.7 GB to 35.2 GB. AtomicChat noted that Nanbeige4.3-33B is unusually sensitive to quantization. Standard llama.cpp presets like Q4_K_M experienced noticeable prediction drift, achieving a 89.9% top-1 match rate against the original BF16 weights. Using custom importance matrices (AD- builds), top-1 agreement improved to 92.6% for AD-Q4_K_M (21.2 GB) and 97.5% for AD-Q6_K (30.1 GB), while aggressive sub-4-bit quantizations dropped below 85% agreement.

Why the Apache 2.0 Release Matters

Hardware economics have made mid-sized open-weight models increasingly attractive. According to figures cited by Startup Fortune, one-year rental prices for Nvidia H100 GPUs increased nearly 40% between October 2025 and March 2026, rising from $1.70 to $2.35 per GPU-hour. Nvidia executives confirmed earlier in the year that rental costs continued an upward trend.

Because Nanbeige4.3-33B carries an Apache 2.0 license, enterprises and independent engineers can self-host internal agent systems without commercial revenue caps or per-token API charges. A quantized 4-bit representation occupies roughly 20 to 21 GB on disk, enabling teams to run the weights on a single 24 GB consumer or workstation GPU—though large KV caches at extended context lengths will require distributed memory or reduced window targets.

Nanbeige has invited developers to contact its team for joint work on domain-specific agents, while the broader community awaits third-party validation and the subsequent distilled Nanbeige4.3-3B release.

Questions people ask

What is the context window size of Nanbeige4.3-33B?

The model natively supports a context window of up to 524,288 tokens (512K).

What license is Nanbeige4.3-33B distributed under?

It is released under a permissive Apache 2.0 license with open weights, allowing unrestricted commercial and personal deployment.

Can Nanbeige4.3-33B process images?

No. The model is text-only in English and Chinese, unlike competing models such as Google's Gemma 4 31B which support vision inputs.

Can the model run on consumer GPUs?

Yes. Community GGUF quantized builds created by AtomicChat allow 4-bit variants (around 20-21 GB) to load onto 24 GB GPUs, though running long context windows will constrain available memory.
