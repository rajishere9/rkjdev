AI Coding Agents Accelerate Legacy Game Decompilation and PC Ports

Autonomous AI coding workflows are turning years-long reverse-engineering projects into week-long sprints, but community pushback over code quality and copyright is mounting.

In short

  • Autonomous AI agents such as Claude and GPT models have completed multi-year game decompilation projects by running against automated byte-matching tests, whereas Qwen was used for static recompilation of Fable 2 in about an hour.
  • Developers have produced playable native PC and browser ports for titles including Super Smash Bros. Melee, Wave Race 64, Fable 2, and Call of Duty: Modern Warfare 2.
  • Major emulation and recompilation communities are fracturing, with repositories such as awesome-recompilations and emulator projects banning unverified, AI-generated code.
  • Corporate IP owners have begun intervening, with Activision and Bethesda issuing takedown notices against high-profile AI recreation projects.

Developers reverse-engineering retro console and PC software are witnessing an abrupt acceleration in their workflows. Autonomous AI agents powered by large language models are solving stubborn functions, converting assembly instructions into C code, and producing native PC ports of classic titles that previously required years of manual human labor, according to reporting by TechSpot. The shift has already enabled functional modern builds of games like Super Smash Bros. Melee, Wave Race 64, and Fable 2, while exposing deep fractures within the open-source emulation and recompilation communities.

Decompilation involves translating compiled machine code back into high-level, human-readable source code. Because compilation discards comments, structure, and variable names, human volunteers historically spent years painstakingly writing candidate C functions until the resulting output behaved identically to the original game. AI coding systems have compressed these timelines because decompilation provides an unambiguous target: matching decompilation, where the generated code must compile into a binary that matches the original byte-for-byte.

The Verifiable Loop Behind Rapid Decompilation

Unlike open-ended software development, matching decompilation offers an automated test harness that requires no human review. As explained by TechSpot, an agent writes candidate code, compiles it using the historical compiler and flags, checks whether the compiled output matches the original executable byte-for-byte, and iterates until it passes. If it fails, the agent inspects the difference and tries again.

This continuous verification loop allows developer workflows to run unattended for hours. In late 2025, a developer working on the Nintendo 64 game Snowboard Kids 2 configured Anthropic's Claude inside an automated script that picked the simplest remaining function, attempted a match up to ten times, and committed successful matches directly to the repository, according to TechSpot. The developer completed more progress in three weeks than in the prior three months, while developer Chris Lewis separately decompiled the original Snowboard Kids in 84 days down from nearly two years.

Similar workflows broke logjams on other long-running efforts. The community decompilation of Super Smash Bros. Melee, which started in July 2020, reached 100 percent completion on September 7, 2026, after developers used GPT-6 Astra to solve the final remaining functions, as reported by TechSpot. Shortly after, developers used Claude to assemble "melee-pc," a native port for Windows, Linux, and Android supporting rendering resolutions up to ten times the original GameCube hardware.

From Assembly to Native PC Ports in Hours

AI agents are also transforming static recompilation, an alternative technique that translates console binaries directly into native modern code without running an emulator. On modern frameworks such as N64Recomp and ReXGlue, developers are layering AI models to automate the glue logic required for graphics, audio, and controller input.

In September 2026, an independent developer used the ReXGlue framework alongside a locally hosted Qwen3.8 27B model to produce a bootable, native PC port of the Xbox 360 title Fable 2 in approximately one hour, according to Dot Esports. The resulting unofficial port runs at uncapped frame rates and introduces mouse and keyboard controls. Similarly, the Wave Race 64 developer claimed that Claude Code generated every line of the project's code, scripts, and documentation, as reported by Dot Esports, relying on established rendering libraries like RT64.

Other experiments have scaled up model usage dramatically. Developer Maurice Heumann used a fleet of 17 parallel Claude Code agents to decompile the 2009 PC release of Call of Duty: Modern Warfare 2, TechSpot reported. The automated effort burned between 600 billion and 700 billion tokens across three months to deliver a playable executable; after agents initially produced broken logic, automated guardrails were introduced, which allowed four agents to decompile one-third of the game in August.

Community Backlash and Technical Debt

Despite the rapid pace of releases, the surge in AI-generated ports has sparked widespread resistance among veteran reverse engineers. Critics argue that "vibe-coded" ports frequently exhibit subtle physics anomalies, unhandled edge cases, and unmaintainable code structures, according to PC Gamer.

During development of an AI-assisted port of Donkey Kong 64, maintainers discovered the agent had modified RT64, the core rendering library shared across multiple N64 ports, introducing rendering regressions. In response, a rival team launched DK64: ReKONGpiled, explicitly campaigning against unverified AI code. The creators of Astrocore (a native port of Super Mario Galaxy) advertise their release as "100% coded by humans," while the awesome-recompilations directory adopted rules barring vibe-coded projects from being showcased.

Established open-source projects including the mGBA and QEMU emulators have instituted complete bans on AI-generated code. Developers warn that when AI systems face ambiguous binary functions lacking strict byte-match checks, they tend to fabricate readable logic that introduces hidden errors into netcode, physics engines, and graphics pipelines.

Legal Takedowns and the Enterprise Horizon

Legal pressures are also mounting as automated game ports multiply. Traditional fan decompilations avoid copyright claims by requiring players to supply their own game discs or ROM images. However, multiple recent AI-assisted browser projects packaged proprietary game assets directly, prompting rapid legal crackdowns, TechSpot noted. Activision issued copyright takedowns against Heumann's Modern Warfare 2 repository and footage, while Bethesda sent a cease-and-desist letter shutting down Fallout: New York, an AI-assisted browser adaptation.

The implications of automated decompilation extend beyond retro gaming into enterprise computing. Anthropic has highlighted Claude's ability to analyze and modernize legacy COBOL codebases, which process approximately 95 percent of United States ATM transactions. While companies like Itaú and a major automaker that migrated a 25,000-line COBOL workflow to AWS Lambda have used automated verification loops to rewrite predictable COBOL batch jobs, analysts urge caution. Research firm Gartner projected that more than 70 percent of mainframe migrations begun in 2026 will fail due to executives overestimating the capabilities of generative AI.

As coding models grow more capable, the boundary between labor-intensive reverse engineering and automated reconstruction will continue to blur. For both hobbyist game preservationists and enterprise IT architects, the primary challenge is shifting from the speed of code generation to the rigor of long-term verification and software maintenance.

Questions people ask

What is the difference between decompiling and static recompilation?

Decompilation reverses machine code back into high-level, human-readable source code like C. Static recompilation translates original binary code from one console architecture directly into executable instructions for modern operating systems without recreating human-readable source or running a runtime emulator.

Why do AI agents succeed at game decompilation?

Decompilation provides an objective verification loop. In matching decompilation, the agent compiles its code and tests whether the output matches the original game binary byte-for-byte, allowing models to iterate autonomously without requiring manual human review.

Why are emulator communities pushing back against AI-generated ports?

Veteran developers point out that AI models frequently introduce subtle bugs into netcode, timing, and rendering when exact byte matches are not possible. The resulting code can create technical debt that is difficult for human contributors to debug or maintain.
