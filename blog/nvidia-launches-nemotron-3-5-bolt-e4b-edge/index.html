NVIDIA Launches Nemotron-3.5-Bolt-E4B for Edge Robotics and Gaming

The compact 4-gigabyte model brings conversational reasoning, multi-turn tool use, and 64K context windows directly to local PCs, robotics, and edge hardware.

In short

  • NVIDIA released Nemotron-3.5-Bolt-E4B on October 23, 2026, delivering an open 4B effective parameter model that operates in roughly 4GB of memory.
  • Post-trained from Google's Gemma-4-E4B-it, the model is built for edge hardware including Jetson modules, RTX GPUs, and AI PCs.
  • According to NVIDIA's internal benchmark evaluations, the model scored 40% higher on average across conversational agent benchmarks compared to the prior Nemotron-3 Nano-4B while generating up to 80% fewer output tokens.
  • It is released under the OpenMDW-1.1 license for both commercial and non-commercial deployment.
  • According to NVIDIA's reported findings, speculative decoding support via a companion DFlash drafter improves throughput by up to 21% compared to Gemma-4-E4B's original drafter.

NVIDIA officially released Nemotron-3.5-Bolt-E4B on October 23, 2026, introducing an open small language model engineered to run conversational agents and tool-calling routines on local hardware. The release targets embedded robotics, gaming non-player characters (NPCs), and offline voice assistants that must operate within strict memory and latency boundaries.

Built to fit inside approximately 4GB of memory in its quantized 4-bit configuration, the model is available directly through Hugging Face and NVIDIA's developer platform. NVIDIA developed the model to give developers low time-to-first-token latency while preserving headroom for applications or adjacent model pipelines.

Compact Architecture and Training Pipeline

Nemotron-3.5-Bolt-E4B is derived from Google's Gemma-4-E4B-it foundation. It contains 8 billion total parameters with 4 billion effective parameters, allowing it to maintain a compact footprint while supporting a 64K token context window for both inputs and outputs. According to the official Hugging Face model card, the base Gemma model is licensed under Apache 2.0, while NVIDIA distributes Nemotron-3.5-Bolt-E4B under the OpenMDW-1.1 license for commercial and non-commercial applications.

NVIDIA post-trained the model between December 2025 and May 2026 using its NeMo RL and NeMo Gym software frameworks. The training process applied Group Relative Policy Optimization (GRPO) with reinforcement learning from verifiable rewards (RLVR) and reinforcement learning from human feedback (RLHF) across multi-turn dialogue, tool usage, and structured output tasks.

To prevent the verbosity common in reasoning models, NVIDIA implemented group-relative length penalties during post-training. The company also balanced training batches with a 2:1 ratio of non-reasoning to reasoning data, ensuring the model maintains high accuracy even when extended chain-of-thought processing is turned off.

Benchmark Performance Across Interactive Tasks

In evaluations detailed in the NVIDIA technical report, Nemotron-3.5-Bolt-E4B delivered an average quality improvement of approximately 40% over the older Nemotron-3 Nano-4B across conversational agent benchmarks. NVIDIA also reported that the model generated up to 80% fewer output tokens compared to rival models during reasoning-enabled tasks, reducing decoding compute costs and execution times.

On the MultiChallenge benchmark, which measures conversational consistency across multiple turns, the Q4_K_M quantized version of Bolt E4B scored 55.60, outperforming Gemma-4-E4B-it at 39.36 and Qwen3.5 4B at 52.23. In role identity adherence on RoleMRC, the quantized model reached 79.12, compared to 75.24 for Gemma-4 and 62.61 for Qwen3.5.

For agentic execution and tool grounding, Bolt E4B recorded 69.29 on RelyToolBench in Q4_K_M precision, compared to 38.34 for Qwen3.5 4B and 38.97 for Nemotron-3 Nano-4B. On the IHEval instruction hierarchy evaluation, the BF16 edition scored 84.79, outperforming Gemma-4's 67.04 and Qwen3.5's 60.57.

Edge Robotics, Gaming NPCs, and Hardware Efficiency

NVIDIA designed Bolt E4B specifically for local systems where sending data to cloud servers is impractical due to memory, latency, hardware compatibility, cost, or privacy concerns. In an earlier launch announcement reported by TechCrunch, NVIDIA pointed to consumer AI PCs and edge devices as central deployment targets for its compact Bolt family.

To showcase robotics capabilities, NVIDIA demonstrated Bolt E4B operating on a Reachy Mini robot powered by a Jetson Orin Nano with 8GB of memory. In that setup, NVIDIA's Cosmos 3 Edge model provided live computer vision while Bolt E4B interpreted environmental data, triggered motion animation scripts, and generated voice replies.

For gaming environments, the model was tested controlling an interactive blacksmith NPC. The model evaluated player transactions, verified payments, inspected crafting formulas, gathered components, crafted equipment, and transferred items to the player character using autonomous tool calls.

Benchmark measurements on llama.cpp show the model's footprint across varied systems:

  • On a GeForce RTX 5070 (12GB), a context workload of 3,000 input tokens and 50 output tokens consumed 3.5GB of VRAM, with a time to first token of 548 milliseconds and a generation throughput of 133.4 tokens per second.
  • On an RTX Spark system (32GB), the same workload required 3.1GB of VRAM, reaching a 930-millisecond time to first token at 67.0 tokens per second.
  • On an embedded Jetson Orin Nano (8GB), memory usage registered at 4.2GB, producing 15.5 tokens per second with a time to first token of 5,785 milliseconds.

To further boost generation speed, NVIDIA published a companion parallel drafter called DFlash. According to the NVIDIA Research announcement, DFlash predicts multiple tokens in a single forward pass, providing up to 21% higher generation throughput than Gemma-4's original multi-token prediction drafter.

Availability and Tooling Ecosystem

Nemotron-3.5-Bolt-E4B-4GB is available for download in GGUF and BF16 formats from Hugging Face. NVIDIA confirmed deployment support through Ollama, LM Studio, Unsloth, Canonical, the Jetson AI Lab, and the NVIDIA In-Game Inferencing SDK.

The model supports 35 languages and includes runtime chat-template switches for controlling internal reasoning buffers and conversational output modes. Developers can enable thinking tokens when handling multi-step planning or deactivate them to maintain speech-friendly, low-latency dialogue.

Questions people ask

What is NVIDIA Nemotron-3.5-Bolt-E4B?

It is an open 8-billion parameter (4 billion effective) small language model post-trained from Google's Gemma-4-E4B-it, optimized by NVIDIA to run local conversational agents within roughly 4GB of memory.

What hardware can run Nemotron-3.5-Bolt-E4B?

The model is tested for NVIDIA GeForce RTX GPUs (such as the RTX 5070), Jetson Orin Nano, Jetson AGX Orin, RTX Spark AI PCs, and DGX Spark workstations, running on Linux systems with CUDA acceleration.

What license does Nemotron-3.5-Bolt-E4B use?

NVIDIA released the model under the OpenMDW-1.1 license, which allows both commercial and non-commercial use. The underlying base model from Google is governed by Apache License 2.0.

How does DFlash speculative decoding work with Bolt E4B?

NVIDIA released a companion DFlash drafting model that proposes multiple candidate tokens in a single forward pass, increasing inference throughput by up to 21% compared to Gemma-4's standard drafter.
