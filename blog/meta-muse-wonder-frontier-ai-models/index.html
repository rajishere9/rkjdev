Meta Debuts Muse Wonder and Muse Wonder Full Frontier AI Models

Meta Superintelligence Labs debuts its first frontier-grade models, pairing long-horizon agent abilities with a pivot toward proprietary distribution.

In short

  • Meta introduced Muse Wonder and Muse Wonder Full, proprietary multimodal models featuring a 1 million-token context window and inputs across text, image, audio, and video.
  • Muse Wonder Full posts competitive scores across developer and agent evaluations, including 56 on the Artificial Analysis Intelligence Index and 57.5% on SWE-Marathon.
  • Unlike the open-weight Llama family, neither Wonder model is publicly downloadable; Muse Wonder is available via API, while Wonder Full is exclusive to paid Muse Code subscribers.
  • Standard API access for Muse Wonder is priced at $4.00 per million input tokens and $20.00 per million output tokens.

Meta Platforms Inc. officially entered the frontier artificial intelligence tier on October 12, 2026, unveiling its new Muse Wonder and Muse Wonder Full models. Built to challenge top-tier systems from OpenAI and Anthropic, the release marks a deliberate pivot in Meta's broader AI roadmap. Rather than offering open-weight weights for community download as it did with the Llama line, Meta has made both Muse Wonder models fully proprietary, reserving the flagship variant for its dedicated coding ecosystem.

The launch comes approximately 14 months after Meta reorganized its AI research operations into Meta Superintelligence Labs (MSL) under former Scale AI chief executive Alexandr Wang. Writing on X, Meta chief executive Mark Zuckerberg characterized the Wonder family as "a much larger and more advanced class of models" compared to the earlier Muse Spark models released in April 2026. The new systems were trained at Meta's gigawatt-scale Prometheus data center in central Ohio using massive initial pretraining combined with reinforcement learning techniques.

Technical Architecture and Agent Capabilities

Both Muse Wonder models support context windows of roughly 1 million tokens and accept text, image, audio, and video inputs, while returning responses exclusively in text. Rather than focusing strictly on low latency like the lightweight Muse Spark 1.3, Meta designed Wonder to handle complex, long-running agent workflows that require coordinating across external software and recovering from runtime errors.

To power these workflows, Meta introduced two foundational agent mechanisms: Active Memory and Active Focus. Active Memory carries relevant user details, preferences, and operational context across successive sessions, retrieving facts as they become relevant. Active Focus enables the agent to persist through obstacles, try alternate execution paths when tools fail, and seek user confirmation before executing irreversible or consequential actions. In launch demonstrations, Meta highlighted use cases spanning software engineering, legal document analysis, financial modeling, and cross-application planning.

Meta also addressed persistent sector concerns regarding benchmark overfitting, often termed "benchmaxxing." In its model card, Meta reported that Muse Wonder Full generalizes better to unfamiliar, out-of-distribution tasks than earlier iterations, arguing that a fundamentally larger base model prevents post-training optimizations from degrading broader utility.

Benchmark Performance Across Reasoning and Code

Benchmark scores reported by Meta and evaluated by third parties place Muse Wonder Full firmly in the upper bracket of frontier models. On the aggregated Artificial Analysis Intelligence Index v4.3, Muse Wonder Full scored 56, matching Anthropic's Claude Sonnet 5.5 and trailing only Claude Opus 5.5 (58). It outperformed OpenAI's GPT-6 Astra (53), Google's Gemini 4 Argon (53), Anthropic's Claude Fable 5.1 (53), and Meta's base Muse Wonder (52).

Software engineering benchmarks showed significant gains on extended tasks. On SWE-Marathon, an evaluation of long-horizon programming, Muse Wonder Full achieved 57.5% compared to 46.3% for Claude Opus 5.5 and 42.5% for GPT-6 Astra, though Meta noted that tool differences across models reduce experimental control. On DeepSWE 1.1, Wonder Full reached 79.0% against GPT-6 Astra's 74.1%. In terminal environments, Wonder Full jumped to 57.1% on Terminal-Bench 4.0, while solving 94 out of 100 problems on the ProofBench mathematical proof evaluation.

Performance in specialized domains was mixed. Muse Wonder Full led rivals on Harvey's Legal Agent Benchmark (Harvey LAB-AA) with a 13.1% passing rate, ahead of GPT-6 Astra at 8.6% and Opus 5.5 at 4.2%. However, factual recall remains an acknowledged weakness: on the AA-Omniscience knowledge test, Wonder Full recorded 30 points, trailing Opus 5.5 (46) and GPT-6 Astra (43). Meta partially offset this limitation by reducing hallucinations, cutting Wonder Full's hallucination rate to 23% from Spark 1.3's 33%.

Pricing, API Availability, and Access Tiers

Meta has established a stark operational divide between the two model sizes. The standard Muse Wonder model is broadly accessible through the Meta Model API under the identifier muse-wonder-1.0. Standard API usage is priced at $4.00 per million input tokens, $20.00 per million output tokens, and $0.20 per million cached input tokens, with no price escalator for larger context lengths. Developers can also integrate built-in web search for an additional $2.50 per 1,000 queries, subject to rate limits of 3,000 requests and 4 million tokens per minute.

In contrast, Muse Wonder Full cannot be accessed via pay-as-you-go developer APIs or deployed on self-hosted infrastructure. The flagship model is available exclusively to paid subscribers of Meta's Muse Code programming tool. Access requires either the Power Usage plan at $50 per month or the Maximum Usage tier at $200 per month, both of which enforce strict usage ceilings that preclude external application development.

Data privacy policies differ sharply across entry points. The pay-as-you-go API operates under Standard mode, meaning customer inputs and outputs are not retained for model training. Approved API customers can also activate Zero Data Retention, though doing so explicitly disables server-side state, Active Memory, and file uploads. By default, Muse Code subscriptions run in Contributor mode, granting Meta rights to use prompts, code files, and context for future model training unless users manually toggle the setting off.

Safety Evaluations and Meta's Strategic Shift

Safety disclosures in Meta's model card show that unmitigated versions of Muse Wonder Full could reach the high-risk threshold for chemical and biological threat capabilities. To counter these vectors, Meta applied post-training mitigations and system-level classifiers, bringing post-defense assessments down to moderate or lower under the Meta Superintelligence Scaling Framework. On an internal agent misalignment evaluation measuring whether models take harmful steps to prevent deactivation, Meta reported a 0% harmful action rate.

Meta has confirmed that Muse Wonder will soon power the standalone Muse personal assistant for paying subscribers, while Meta plans to build specialized models developed from Muse Wonder for all users of the Muse app. With Meta expecting to spend as much as $145 billion this year to fuel its AI plans, according to Engadget, the Muse Wonder debut demonstrates that Zuckerberg's expensive research restructuring has produced frontier-tier competitive parity, even as Meta steps back from its historic open-source distribution ethos.

Questions people ask

Can developers download the weights for Muse Wonder or Muse Wonder Full?

No. Unlike Meta's earlier Llama models or the smaller Muse Glimmer, neither Muse Wonder nor Muse Wonder Full is released as an open-weight model. The weights are proprietary and cannot be self-hosted.

How can developers access the more powerful Muse Wonder Full model?

Muse Wonder Full is not offered via the Meta Model API. It is currently accessible only through paid Muse Code subscription plans, which start at $50 per month for Power Usage and $200 per month for Maximum Usage.

What are Active Memory and Active Focus?

Active Memory is Meta's system for carrying personal and project context across multiple conversations. Active Focus is an agent capability that allows the model to persist through errors, try alternate strategies, and request human permission before completing major actions.

What does standard Muse Wonder API access cost?

Muse Wonder costs $4.00 per 1 million input tokens, $20.00 per 1 million output tokens, and $0.20 per 1 million cached input tokens. Built-in web searches cost an extra $2.50 per 1,000 queries.
