Meta Launches Muse Wonder AI Models to Challenge OpenAI and Anthropic

Meta Superintelligence Labs released Muse Wonder and Muse Wonder Full, introducing agent memory tools while keeping its top-tier model behind a coding paywall.

In short

  • Meta launched proprietary models Muse Wonder and Muse Wonder Full on October 12, 2026, marking a complete shift away from open weights for its flagship tier.
  • The standard Muse Wonder model is accessible via commercial API for $4.00 per million input tokens and $20.00 per million output tokens, while Muse Wonder Full is exclusive to paid Muse Code subscriptions.
  • On the Artificial Analysis Intelligence Index v4.3, Muse Wonder Full scored 56, matching Claude Sonnet 5.5 and trailing only Anthropic Claude Opus 5.5 at 58.
  • New core agent capabilities include Active Memory for context retention across sessions and Active Focus for self-correction during long multi-step workflows.

On October 12, 2026, Meta officially launched its new flagship artificial intelligence model family, introducing Muse Wonder and Muse Wonder Full. Developed by Meta Superintelligence Labs—a dedicated research division established approximately 14 months ago and led by former Scale AI chief executive Alexandr Wang—the models represent the tech company's push to directly match frontier systems built by Anthropic, OpenAI, and Google. This official release marks a major operational transition for the company: neither Wonder model includes downloadable open-source weights, confirming a closed commercial strategy for its top tier as reported by VentureBeat.

According to Meta's research blog, the models were trained at the company's gigawatt-scale Prometheus data center, located in central Ohio according to AIToolsRecap. The system processes multimodal inputs spanning text, images, audio, and video across an approximate 1-million-token context window, while outputting text. Chief Executive Mark Zuckerberg stated on X that the release represents "a much larger and more advanced class of models" compared to the earlier Muse Spark family introduced in April 2026, coming just six weeks after Spark 1.3 debuted. Following the launch, Meta shares rose 3% on Monday, as detailed by Latent Space.

Active Memory and Active Focus for Autonomous Agents

Rather than framing Wonder solely as a conversational engine, Meta built the architecture to handle sustained, autonomous tasks across personal and professional domains. In its technical overview on the Meta AI Research Blog, the company emphasized two core systems: Active Memory and Active Focus. Active Memory allows the model to preserve personal and professional context across multiple conversations spanning days and weeks, automatically retrieving relevant project details when new tasks arise.

Active Focus equips the models to work through multi-step blockers without abandoning an assignment. Meta claims that when a task becomes difficult, the model will attempt alternate strategies, recover from execution errors, and seek clarification from the user. For sensitive or consequential workflows, Meta stated the agent checks in with human operators before finalizing actions.

Benchmark Performance Across Coding and Legal Tasks

Independent evaluations show Meta has closed the gap with incumbent frontier developers, though results vary by task. According to the independent evaluation firm Artificial Analysis reported by Mashable, on its Intelligence Index v4.3, Muse Wonder Full scored 56 at maximum reasoning effort, while the standard Muse Wonder scored 52. For comparison, Anthropic's Claude Opus 5.5 led the index at 58, Anthropic's Claude Sonnet 5.5 scored 56, OpenAI's GPT-6 Astra scored 53, and Google's Gemini 4 Argon posted 53.

Meta's published model card highlights strong results in software engineering and professional reasoning. On the DeepSWE 1.1 software engineering evaluation, Muse Wonder Full scored 79.0% and standard Wonder scored 78.8%, surpassing Claude Opus 5.5 at 74.2% and GPT-6 Astra at 74.1%. On SWE-Marathon, which measures long-running coding projects, Wonder Full scored 57.5% compared to 46.3% for Opus 5.5 and 42.5% for GPT-6 Astra. On the legal domain benchmark Harvey LAB-AA, Wonder Full posted a score of 13.1, outperforming Astra's 8.6 and Opus 5.5's 4.2, though overall legal scores across all providers remained low.

However, the evaluations also revealed clear limitations. On Terminal-Bench 4.0-AA, Claude Opus 5.5 (59.6%) and GPT-6 Astra (59.1%) both outperformed Wonder Full (57.1%). On medical reasoning evaluated by HealthBench Pro, Claude Opus 5.5 scored 65.6 and Astra scored 65.3, ahead of Wonder Full's 62.3. As noted by VentureBeat, Meta's internal evaluations also relied on different tooling configurations for certain coding comparisons, meaning not all tests occurred under identical conditions.

API Pricing, Availability, and the Muse Code Paywall

Access to the Muse Wonder family is split across tiers. The standard Muse Wonder model is available immediately through the Meta Model API under the model identifier muse-wonder-1.0. Meta priced input tokens at $4.00 per million, output tokens at $20.00 per million, and cached input tokens at $0.20 per million, alongside an optional web search fee of $2.50 per 1,000 queries. Rate limits are capped at 3,000 requests per minute and 4 million tokens per minute. This token pricing matches Anthropic's standard Claude Opus 5.5 rates exactly, while undercutting OpenAI's GPT-6 Astra standard rates of $10.00 input and $50.00 output per million tokens.

However, developers looking to integrate Meta's highest-performing model cannot do so programmatically. Meta has restricted Muse Wonder Full entirely from the public API, reserving it exclusively for paid subscribers to its Muse Code programming tool, as outlined by AIToolsRecap. Muse Code subscribers must pay either $50 per month for the Power Usage plan or $200 per month for the Maximum Usage plan to access Wonder Full. The models will also roll out to paid subscribers of Meta's consumer agent app Muse, which recently surpassed 5 million downloads.

Privacy Settings and Data Governance

Meta introduced distinct data handling policies alongside the launch. The pay-as-you-go Meta Model API operates under Standard Mode, which guarantees customer inputs and outputs are not used to train future AI models. Conversely, Muse Code subscriptions default to Contributor Mode, which permits Meta to use submitted prompts, code repositories, files, and outputs for model training. While users can manually turn Contributor Mode off, Meta's terms forbid submitting sensitive, confidential, or personal data while the feature is active.

Enterprise customers can request Zero Data Retention (ZDR) for the Model API, but selecting this option introduces technical tradeoffs. Turning on ZDR disables server-side conversation state, file uploads, background execution, and integrated web searches. Because these limitations disable memory and persistence, developers running ZDR cannot take advantage of Wonder's headline Active Memory feature.

Meta's push into proprietary frontier models comes amid elevated spending, with the company projecting its 2026 AI-related investments could reach $145 billion, according to The Hindu. While Zuckerberg signed an administration-backed AI safety pledge alongside leaders from OpenAI, Anthropic, Google, and Nvidia in September 2026, Meta's release schedule demonstrates that it is pressing forward with commercial deployment rather than adopting voluntary development pauses.

Questions people ask

How can developers access Muse Wonder and Muse Wonder Full?

Standard Muse Wonder is available through the Meta Model API at $4.00 per million input tokens and $20.00 per million output tokens, as well as via Muse Code. Muse Wonder Full is not available on the API and can only be accessed through paid Muse Code subscriptions costing $50 or $200 per month.

Are the weights for Muse Wonder open source like Llama?

No. Unlike Meta's older Llama models or its Muse Glimmer release, both Muse Wonder and Muse Wonder Full are proprietary models. Meta does not offer downloadable weights or self-hosting options.

What are Active Memory and Active Focus?

Active Memory is Meta's system for retaining and recalling context across conversations over days or weeks. Active Focus is an agentic execution feature designed to keep the model pursuing complex goals, trying alternative strategies and self-correcting when encountering errors.
