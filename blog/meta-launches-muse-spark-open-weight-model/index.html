Meta Launches Muse Spark Open to Challenge Rival Open Models

The 816-billion-parameter open-weight model brings 1-million-token multimodal reasoning to Apple Silicon and enterprise Nvidia Blackwell systems.

In short

  • Meta launched Muse Spark Open, an 816B-parameter (42B active) mixture-of-experts model with a 1-million-token context window.
  • The model is optimized to run locally across two Apple M5 Ultra Mac Studios using Apple's MLX framework, requiring 1TB of unified memory.
  • Nvidia released an accompanying DFlash 2 draft model to accelerate inference on Blackwell GB300 systems via vLLM and SGLang.
  • Meta positioned the release against international open-weight systems, reporting benchmark gains over Chinese models Kimi K3 and GLM 5.3 on agentic tasks.

On October 15, 2026, Meta released the weights for Muse Spark Open, an 816-billion-parameter multimodal AI model designed for agentic tasks, coding, and multi-step reasoning. Featuring 42 billion active parameters per forward pass and a context window reaching 1 million tokens, the model is available to download on Hugging Face under Meta's Muse Model License. New technical disclosures outline how Meta worked alongside hardware vendors to support on-device desktop execution on Apple Silicon and server-scale inference on Nvidia systems.

Alexandr Wang, Meta's chief of AI, called Muse Spark Open "the most capable US open-weight model to date" in posts on X, while background reporting by The Guardian explained that open-weight models provide parameter access to developers and noted competition from leading Chinese models.

Apple Silicon Integration and Local Hardware Requirements

A notable technical development in the launch is Meta's collaboration with Apple. According to 9to5Mac, Muse Spark Open leverages Apple's open-source MLX array framework to distribute inference across Apple unified memory architecture. Mark Zuckerberg stated on X that the model was optimized for Mac Studio hardware in coordination with Apple head John Ternus.

Local deployment requires substantial memory. As detailed by Engadget, running Muse Spark Open on desktop hardware requires roughly 1TB of RAM. This setup uses two Mac Studio systems equipped with M5 Ultra chips offering 512GB of unified memory each, joined so that the M5 Ultra integrated GPUs can access the model across 1.2 TB/s of memory bandwidth. Meta reported testing on-device agentic workflows on the hardware, including using Muse Code for shipping real iOS changes (bug fixes, new features, full build) to the open-source Mastodon client Ice Cubes and controlling DaVinci Resolve frame-by-frame for automated video cropping.

Engadget noted that setups can also run on four 256GB Mac Studios, an arrangement priced near $38,000, while CNET noted that single base M5 Ultra units start at $5,499 with 96GB memory.

Nvidia Speculative Decoding and Server Inference

Beyond desktop Mac Silicon, server infrastructure providers rolled out immediate support. On October 16, 2026, Nvidia published Muse-Spark-Open-816B-A42B-DFlash2, a dedicated 4.38-billion-parameter draft model built with Nvidia Model Optimizer 0.47 for DFlash 2 speculative decoding.

The DFlash 2 draft model features 5 dense decoder layers with non-causal sliding-window attention across a 2,048-token window, sharing token embeddings and output heads with Meta's target checkpoint. Testing conducted on Nvidia Blackwell GB300 systems using vLLM demonstrated average acceptance lengths between 3.47 and 3.87 tokens per step on MT-Bench and the SPEED-Bench qualitative split, while the throughput split averaged 3.03 to 3.35 tokens per step. Serving configurations for SGLang allow teams to deploy an NVFP4 quantized checkpoint of Muse Spark Open across four Blackwell GPUs using tensor and expert parallelism.

According to Meta's developer documentation, runtime and serving integrations at launch include vLLM, SGLang, llama.cpp, and Hugging Face, alongside cloud catalog support on Amazon SageMaker AI, Google Cloud Model Garden, and Microsoft Foundry Models.

Competitive Benchmarks and Industry Impact

Meta positioned Muse Spark Open as a direct response to leading Chinese open-weight models, including Alibaba's Qwen, Moonshot AI's Kimi K3, and Z.ai's GLM family, as noted by The Guardian. According to benchmarks released by Meta and reported by Engadget, Muse Spark Open outperformed GLM 5.3 and Kimi K3 on evaluations measuring visual reasoning and multi-step agentic performance.

As reported by ETEnterpriseAI, open weights provide enterprises with private control over data governance and deployment environments without continuous cloud API billing. Hosted API availability has also rolled out through providers including Fireworks AI, Together AI, Groq, Baseten, and Modal, providing hosted alternatives for organizations that do not manage on-premises clusters.

Questions people ask

What are the core technical specifications of Muse Spark Open?

Muse Spark Open features 816 billion total parameters with 42 billion active parameters in a mixture-of-experts configuration, a 1-million-token context window, and multimodal input support covering text, images, video, and audio.

What hardware is required to run the model locally?

Local execution requires 1TB of unified RAM, which can be achieved using two Apple Mac Studios configured with 512GB M5 Ultra chips running Apple MLX, or four 256GB Mac Studio units.

How does Nvidia accelerate Muse Spark Open on servers?

Nvidia released the Muse-Spark-Open-816B-A42B-DFlash2 draft model, a 4.38-billion parameter checkpoint designed to accelerate inference on Blackwell GPUs via DFlash 2 speculative decoding in vLLM and SGLang.
