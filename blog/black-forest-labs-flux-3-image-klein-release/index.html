Black Forest Labs Releases FLUX 3 Image Klein Open-Weights Model

The 5.6-billion-parameter model retains native 4K output from the larger FLUX 3 Image model announced in July 2026, bounding-box composition, and consumer GPU support under a revenue-tiered license.

In short

  • Black Forest Labs released FLUX 3 Image Klein, a 5.6-billion-parameter open-weights image generator and editor.
  • The model runs locally on consumer graphics cards with as little as 8 GB of VRAM using an INT8 build in ComfyUI.
  • Workflows support native 4K output, multi-reference editing with up to 10 images, and precise layout controls via bounding boxes.
  • The release is governed by the FLUX Kommunity License, permitting free commercial use only for organizations making under $5 million annually.
  • While a prompt upsampler is required to avoid generic output, BFL's 9-billion-parameter model is not strictly required because any LLM can be used with the provided system prompt.

On October 15, 2026, AI research studio Black Forest Labs announced the release of FLUX 3 Image Klein, a 5.6-billion-parameter open-weights model designed for text-to-image synthesis, image editing, and multi-reference generation. Built to execute on consumer-grade hardware, the new architecture delivers high-resolution synthesis up to native 4K while operating on GPUs with as little as 8 GB of video memory. The release marks the second public model from the company's FLUX 3 family, following the earlier launch of its robotics-oriented FLUX 3 Action checkpoint.

The system combines generation, single-reference image editing, and compositions drawing from up to 10 reference images into a unified transformer backbone. Alongside the core weights, Black Forest Labs published companion tools and quantized formats to enable local execution across standard open-source pipelines, including ComfyUI and Hugging Face Diffusers.

Dual Checkpoints and the Prompt Upsampling Requirement

Black Forest Labs structured the release into two primary model checkpoints: an undistilled base version and a step-distilled variant. The base model operates across 50 steps with a default classifier-free guidance setting of 3.5, targeted at developers conducting research, downstream adaptation, and Low-Rank Adaptation (LoRA) fine-tuning. For production serving and direct generation, the step-distilled model executes in 16 steps without classifier-free guidance, providing roughly six times faster local generation.

A central operational change in the FLUX 3 pipeline is the strict requirement for a prompt upsampler. As documented in the official model card on Hugging Face, the 5.6B transformer takes comprehensive, paragraph-length scene descriptions rather than short text prompts. Passing short, raw text prompts directly into the diffusion pipeline produces generic visual output.

To address this dependency, the company released the FLUX 3 Image Klein Prompt Upsampler, a separate 9-billion-parameter vision-language model built as a fine-tune of Alibaba Cloud's Qwen3.5-9B under the Apache 2.0 license. The upsampler rewrites short user commands into detailed technical prompts specifying camera angle, framing, lighting conditions, textures, and subject materials. For image editing, the upsampler looks at reference images and writes the instruction around what is in them: what changes, what stays, by appearance.

Layout Control and Hardware Specifications

FLUX 3 Image Klein retains native bounding-box conditioning for layout composition and targeted edits from the larger FLUX 3 Image model. While the official model repository on GitHub uses a 0-to-1 coordinate range passed via JSON, the ComfyUI Hugging Face repository documents appending coordinate tables formatted on a normalized 0-to-1000 coordinate grid directly to the prompt payload. Users can define rectangular spatial bounds to guide element placement rather than as a hard mask, though edits can alter content outside the requested box unless using the API's pixel restoration feature.

The image transformer uses Alibaba's Qwen3-VL-4B-Instruct as its dedicated text encoder, keeping linguistic evaluation separate from visual synthesis. In uncompressed BF16 precision, the generator transformer requires 11.2 GB of memory, while the Qwen3-VL-4B text encoder requires 8.9 GB. To lower memory barriers, Black Forest Labs worked with NVIDIA to build FP8, INT8, and NVFP4 checkpoints.

Through an INT8 build repackaged for ComfyUI, the generator transformer footprint drops to 5.8 GB and the text encoder drops to 4.9 GB. This allows the system to operate on 8 GB cards such as the NVIDIA GeForce RTX 3070 and RTX 4070. On an RTX 4070 running ComfyUI, the distilled INT8 model produces a 1-megapixel image in 8.9 seconds for text generation and 18.9 seconds for an edit. On a flagship GeForce RTX 5090, generation takes 4.1 seconds and editing takes 7.2 seconds.

For enterprise data center environments, NVIDIA Blackwell systems using NVFP4 precision reach sub-second latencies. On DGX hardware, generation of a 1-megapixel image completes in 0.59 seconds, while a 2K (2,048 × 2,048) image takes 2.2 seconds.

Benchmarks and Internal Evaluations

In evaluation charts published by Black Forest Labs, FLUX 3 Image Klein demonstrated substantial quality gains over its predecessors. Against the prior 9-billion-parameter FLUX.2 [klein], the new 5.6B model achieved a 91 Elo increase in text-to-image preference and a 70 Elo gain in image editing benchmarks, despite a 38 percent decrease in parameter count.

Black Forest Labs reported that Klein outperformed open-weights alternatives such as the 7B Qwen-Image 2.1 and the 12.9B Krea 2 in internal evaluations for image editing. The company's internal comparisons also positioned the distilled model above closed commercial offerings including Ideogram V4.5 and FLUX.2 [pro].

However, trade publication VentureBeat reported limitations regarding the published benchmark data. The outlet pointed out that Black Forest Labs omitted sample sizes, prompt sets, and uncertainty metrics from its public charts. Furthermore, the official speed comparisons measured GeForce GPUs using INT8 while data-center systems ran NVFP4, preventing direct silicon-level comparisons. The benchmark evaluations also omitted comparisons at full 4K output resolutions and did not include tests against OpenAI's GPT Image 2.5 or Google's Nano Banana 2.1.

Licensing Terms and API Availability

While the code and the prompt upsampler are published under the permissive Apache 2.0 license, the core image model weights are governed by the FLUX Kommunity License v1.0. As outlined by the FLUX Kommunity License terms, the license allows free commercial use exclusively for individuals and entities with gross annualized revenues under $5 million, aggregated across all corporate affiliates.

Organizations generating $5 million or more in annual revenue are excluded from free commercial self-hosting. Enterprise teams exceeding this threshold must purchase commercial self-hosting licenses or route workloads through the official Black Forest Labs API. The license also restricts outputs from being used to train competing foundation models and strictly forbids military, surveillance, or biometric applications.

For managed infrastructure, Black Forest Labs provides hosted access to the distilled model via its API, with pricing tiered by output resolution: $0.008 for 768 × 768 pixels, $0.009 for 1K (1,024 × 1,024), $0.011 for 1.5K, $0.014 for 2K, and $0.036 for native 4K renders. The hosted endpoint integrates proprietary prompt expansion and pixel restoration pipelines directly into the generation loop.

Fine-tuning pipelines are operational from day one. Community developers can adapt the base model using Ostris's AI Toolkit, Diffusers scripts, and official recipes included in NVIDIA NeMo AutoModel, providing smaller studios with an accessible foundation for custom asset generation.

Questions people ask

What hardware is required to run FLUX 3 Image Klein locally?

The model runs on consumer NVIDIA GeForce RTX GPUs with as little as 8 GB of VRAM using the INT8 build in ComfyUI. The uncompressed BF16 generator weights require 11.2 GB of VRAM, with an additional 8.9 GB required for the text encoder unless quantized.

Can businesses use the open weights commercially for free?

Commercial use is free only for individuals and organizations with gross annualized revenue under $5 million under the FLUX Kommunity License. Companies earning $5 million or more must license the weights commercially or use the paid API.

Why is the prompt upsampler required during inference?

FLUX 3 Image Klein was trained on dense, paragraph-long scene descriptions. Passing short natural language prompts without expansion results in generic imagery, though any preferred LLM equipped with BFL's provided system prompt can be used to upsample prompts instead of the 9B model.

How does FLUX 3 Image Klein handle layout control?

The model accepts bounding-box coordinates on a 0-to-1000 grid appended to the prompt payload, allowing users to define positions and dimensions for specific objects during generation or editing.
